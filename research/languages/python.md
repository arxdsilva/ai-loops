> **Summary:** A strong Python team uses `uv` with `pyproject.toml` and a committed `uv.lock`, a `src/` layout, `ruff` for lint and format, `mypy` or `pyright` in strict mode, `pytest` with coverage.py, and `import-linter` for layers. There is **no data-race detector** for ordinary Python, so the race policy is `none` plus a substitute (random order, parallel workers, dev mode, optional free-threaded thread-stress). The three biggest gaps against loops: (1) the gate, the coverage parser and the post-edit and stop hooks are all Go-only, so a Python repo gets no hard test gate; (2) there are no repo-management, packaging or security rules at all (lockfile, `pip-audit`, `bandit`, supply chain); (3) the arch checker has no Python import parser or `import-linter` bridge, and Django-style apps fight the hexagonal layout.

Rules follow [TAXONOMY.md](TAXONOMY.md), using the row format `ID | Rule | Why | Sev | Source | loops today | Enforce`. Gaps are judged against [LOOPS_BASELINE.md](LOOPS_BASELINE.md). Where a row says `covered`, the neutral rule is in `specs/WORKFLOW.md` (§n), `specs/HEXAGONAL_ARCHITECTURE.md` or `ROLES.md`.

## 3. ARCH: architecture

Styles in Python. Hexagonal/clean: expressed with `typing.Protocol` ports and plain dataclasses; fits FastAPI, Flask and plain ASGI well; Django fights it (apps own models, ORM and admin; use a thin service layer or keep Django as an adapter). Layered/MVC: Django and Flask defaults. DDD tactical: `@dataclass(frozen=True)` value objects, aggregates as plain classes, repositories as Protocols ([Cosmic Python](https://www.cosmicpython.com/book/preface.html)). CQRS/event sourcing: explicit command and query handlers; event store in Postgres; libraries are small, so hand-roll. Event-driven: Celery/Dramatiq/Kafka clients with outbox. Modular monolith: default choice; import-linter enforces module boundaries. Serverless: AWS Lambda Powertools, cold-start sensitive, keep the composition root cheap. Actor model: no first-class support (Ray, Thespian); avoid.

ARCH-02 tree (FastAPI-style hexagon; for Django see FW):

```
src/orders/
  domain/            # pure: dataclasses, enums, domain errors; no I/O, no clock
    order.py  money.py  errors.py
  application/       # use cases + ports (Protocols defined by the consumer)
    place_order.py  ports.py
  adapters/
    inbound/http/    # FastAPI routers, request/response schemas (Pydantic)
    inbound/cli/  inbound/worker/
    outbound/db/     # SQLAlchemy repos, Alembic env
    outbound/clock.py  outbound/http_clients/
  compose.py         # composition root: builds adapters, wires use cases
  main.py            # ASGI app factory (create_app) only
```

## 5. CONC: concurrency and the `-race` equivalent

**Loops race policy: `mode = none`.** CPython has no built-in or flag-based data-race detector; a TSan build exists but is a separate interpreter build. ## Top 10 footguns

1. **Mutable default argument.** Bad: `def add(x, acc=[])`. Fix: `acc: list[int] | None = None` and create inside, or `field(default_factory=list)`. ([Ruff B006](https://docs.astral.sh/ruff/rules/mutable-argument-default/))
2. **Blocking call inside `async def`.** Bad: `requests.get(...)` in a handler. Fix: `httpx.AsyncClient` or `await asyncio.to_thread(...)`. ([FastAPI async](https://fastapi.tiangolo.com/async/))
3. **Swallowed `CancelledError` / bare `except`.** Bad: `except Exception: pass` or catching `BaseException` in a task. Fix: narrow the type and re-raise `CancelledError`. ([asyncio docs](https://docs.python.org/3/library/asyncio-task.html))
4. **Dangling `create_task`.** Bad: `asyncio.create_task(job())` with no reference. Fix: `TaskGroup`, or keep a set with `add_done_callback(discard)`. ([asyncio docs](https://docs.python.org/3/library/asyncio-task.html))
5. **`pickle`/`yaml.load` on untrusted data.** Fix: JSON, `yaml.safe_load`, Pydantic. ([pickle docs](https://docs.python.org/3/library/pickle.html))
6. **Naive or deprecated datetimes.** Bad: `datetime.utcnow()`. Fix: `datetime.now(UTC)`. ([datetime docs](https://docs.python.org/3/library/datetime.html))
7. **`assert` as validation.** Bad: `assert user.is_admin`. Fix: `raise PermissionError`. ([bandit B101](https://bandit.readthedocs.io/en/latest/plugins/b101_assert_used.html))
8. **Import-time side effects and cycles.** Bad: opening a DB connection at module import. Fix: build it in `compose.py`, enforce with import-linter. ([import-linter](https://import-linter.readthedocs.io/en/stable/))
9. **Float money / mutable hash keys.** Fix: `Decimal` or integer cents; frozen dataclasses. ([decimal docs](https://docs.python.org/3/library/decimal.html))
10. **Thinking the GIL makes code thread-safe.** Bad: `counter += 1` shared between threads. Fix: a `Lock` or a queue; test on a free-threaded build with pytest-run-parallel. ([py-free-threading](https://py-free-threading.github.io/testing/))

## Open questions

1. **Race policy.** Is `none` with a substitute acceptable as the "equivalent" in `ROLES.md`'s hard rule? Free-threaded builds and TSan CPython exist but are not a default for most backends. The maintainer must decide whether the substitute is a hard gate or advisory.
2. **Free-threaded adoption.** Many wheels still re-enable the GIL as of 2026-11; `pytest-run-parallel` also auto-skips tests using `capsys`, `monkeypatch`, `mock` (older versions). The sources do not agree on a minimum interpreter for production use.
3. **Coverage in one argv.** Settled by the verifier: `--cov-report=xml:path` is documented and works; a bare `--cov` honours `[tool.coverage.run] source`.
4. **mypy vs pyright.** Both are credible; the pack chooses `mypy --strict` as gate but sources do not settle which is better (pyright is faster; mypy plugins serve Django/SQLAlchemy). Maintainer should pick or allow either via config detection. A newer Rust checker family (ty, pyrefly) was not evaluated.
5. **Sources.** Mostly checked by the B2 verifier (12 sources opened, all supportive); the remaining unfetched URLs are stable documentation pages.
6. **pylock.toml.** Settled: `uv export --format pylock.toml` works in uv 0.13.x.
7. **`import_regex` is a fallback.** A regex cannot resolve relative imports or multi-line parenthesised imports; the pack should use an `ast`-based parser or delegate to `lint-imports`.
8. **Schema extensions.** The LOOPS block extends the TAXONOMY §15 schema: `checks[].env` (env vars for one check), `checks[].when_file` (run only if the file exists, here `uv.lock`), `checks[].fallback_argv` (used when `when_file` is absent or a plugin is missing), `checks[].install`, check kinds `typecheck`, `arch` and `sast` beyond the Go example, and `coverage.default_path`, `coverage.alternate`, `coverage.data_file`, `coverage.diff_tool`. The maintainer should accept, rename or drop them when the pack schema is fixed.
9. **Missing test plugins.** The required test argv needs pytest-randomly, pytest-xdist and pytest-cov. Proposed loops behaviour: if a plugin is missing, run `fallback_argv` (plain pytest with coverage) and log an override; if pytest-cov is missing, fail, since the coverage gate cannot be computed.
