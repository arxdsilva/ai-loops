# Scala rules (the `scala` pack)

Scala 3.10.0 current, 3.9.x LTS (3.3.x LTS conservative floor), Scala 2.13.18 last 2.x; sbt 1.13.x verified, sbt 2.0.x supported with a re-verified coverage path; JDK 21 or 25 LTS. As of 2026-11. Source: `research/languages/scala.md` (rule IDs kept so the trace holds). Pack data: `specs/languages/scala/pack.json`. Universal rules are not repeated here: layering is `specs/ARCHITECTURE.md`, design limits `specs/SOLID.md`. The project's own config (`build.sbt`, `.scalafmt.conf`, `.scalafix.conf`, framework conventions) wins over a rule here; log each override with `loops run override`.

## REPO - repository and project management

- **`SCALA-REPO-01`** (MUST) Use the standard Maven-style layout per subproject: `src/main/scala`, `src/main/resources`, `src/test/scala`, `src/test/resources`; package names mirror directories (`com/acme/domain/Order.scala` has `package com.acme.domain`). sbt, Metals, scoverage and the loops arch resolver all assume it. ([source](https://www.scala-sbt.org/1.x/docs/Directories.html))
- **`SCALA-REPO-02`** (MUST) Model hexagonal layers as sbt subprojects with explicit `dependsOn` edges (`application dependsOn domain`, adapters `dependsOn application`, `app` aggregates everything); never let `domain` depend on an adapter project. The compiler then rejects a wrong-direction import because the classes are not on the classpath. ([source](https://www.scala-sbt.org/1.x/docs/Multi-Project.html))
- **`SCALA-REPO-03`** (SHOULD) Keep one root `build.sbt` with `lazy val` projects and a root project that `aggregate`s all (`publish / skip := true`); share settings through a `commonSettings` sequence or a custom `AutoPlugin` under `project/`. Avoids settings drift between subprojects. ([source](https://www.scala-sbt.org/1.x/docs/Multi-Project.html))
- **`SCALA-REPO-04`** (SHOULD) Choose the build tool per repo: sbt by default (broadest plugin ecosystem, scoverage/scalafix/native-packager); Mill when the team wants a typed, fast build with `mill.main.build`; scala-cli only for scripts, spikes and single-module tools. Do not mix two build tools in one module graph. Tool sprawl breaks CI and Metals import. ([source](https://mill-build.org/))
- **`SCALA-REPO-05`** (SHOULD) Bootstrap with `sbt new scala/scala3.g8` (or the company template) and add on day one: `.scalafmt.conf`, `project/build.properties`, `scalafix`, tpolecat flags, CI, `.gitignore`, license. Starter gives a Scala 3 compile target and sbt layout. ([source](https://docs.scala-lang.org/scala3/getting-started.html))
- **`SCALA-REPO-06`** (MUST) Declare every dependency with `%%` (or `%%%` for Scala.js/Native), pin exact versions, centralise in `project/Dependencies.scala`, and commit no build output. sbt has no lockfile by default; for reproducibility use `sbt-lock`/`sbt-dependency-lock`-style tooling or a pinned Coursier mirror, and treat `dependencyTree` output as the review artifact. Scala artifacts carry the binary version suffix; `%` silently resolves the wrong artifact. ([source](https://www.scala-sbt.org/1.x/docs/Library-Dependencies.html))
- **`SCALA-REPO-07`** (SHOULD) Automate dependency updates with Scala Steward (the Scala-aware updater) or Renovate; give it `.scala-steward.conf` pins for LTS Scala and JDK. Generic Dependabot misreads `build.sbt` and Scala suffixes. ([source](https://github.com/scala-steward-org/scala-steward))
- **`SCALA-REPO-08`** (SHOULD) Submit the dependency graph to GitHub (`sbt-github-dependency-graph` / `scalacenter/sbt-dependency-submission`) so Dependabot alerts work on sbt builds. sbt manifests are not parsed natively. ([source](https://github.com/scalacenter/sbt-dependency-submission))
- **`SCALA-REPO-09`** (SHOULD) Remove unused dependencies with `sbt-explicit-dependencies` (`undeclaredCompileDependenciesTest`, `unusedCompileDependenciesTest`) or `-Wunused` plus review. Transitive dependency leaks break at upgrade. ([source](https://github.com/cb372/sbt-explicit-dependencies))
- **`SCALA-REPO-10`** (MUST) Libraries: SemVer, `sbt-ci-release` for Maven Central (Sonatype Central) publishing from tags, PGP signing, `sbt-mima-plugin` (`mimaPreviousArtifacts`) for binary compatibility, publish for Scala 3 and 2.13 where needed. Services: release a Docker image, not a library. Binary incompatibility is the Scala ecosystem's biggest release hazard. ([source](https://github.com/sbt/sbt-ci-release))
- **`SCALA-REPO-11`** (MUST) Pin sbt in `project/build.properties` (`sbt.version=2.0.12` or the 1.x line for plugins not yet ported), Scala in `scalaVersion`, and JDK in `.sdkmanrc`/`.tool-versions`; use `sbt` launcher via `sbtn`/coursier `cs setup`. sbt resolves the pinned version per project. ([source](https://github.com/sbt/sbt/releases))
- **`SCALA-REPO-12`** (MUST) `.gitignore` must contain `target/`, `project/target/`, `project/project/`, `.bsp/`, `.bloop/`, `.metals/`, `.idea/`, `*.class`, `*.log`, `metals.sbt`, `.vscode/` (Metals-generated parts), `.scala-build/`, `.ammonite/`. Build, BSP and IDE output must never be committed. ([source](https://github.com/github/gitignore/blob/main/Scala.gitignore))
- **`SCALA-REPO-13`** (MUST) Commit `.scalafmt.conf` with a pinned `version = ...`, `runner.dialect`, and `.editorconfig` for charset/newline; run `scalafmtCheckAll` in pre-commit or CI. Formatter versions change output. ([source](https://scalameta.org/scalafmt/docs/configuration.html))
- **`SCALA-REPO-14`** (SHOULD) CI stages: restore cache (Coursier + sbt + ivy) → `scalafmtCheckAll scalafmtSbtCheck` → `scalafixAll --check` → `compile` with `-Werror` → `coverage test coverageReport` → dependency scan → `Docker/publishLocal`; matrix over JDK 21/25 and Scala 3 LTS + latest. One pipeline shape per repo. ([source](https://www.scala-sbt.org/1.x/docs/Testing.html))
- **`SCALA-REPO-15`** (SHOULD) Use conventional commits; generate the changelog from tags (release-drafter or `sbt-ci-release`); sign commits where policy asks. Conventional commits drive loops release levels. ([source](https://www.conventionalcommits.org/))

## TOOL - toolchain
- **`SCALA-TOOL-01`** (SHOULD) Greenfield services: Scala 3.9.x LTS (3.3.x LTS if a dependency lags); libraries cross-build 3.3 LTS plus 2.13. Treat Scala 3.10.x "Next" as opt-in. Migrate 2.13 to 3 with `-Xsource:3`, scalafix `MigrationRewrites` (Scala 3 migration plugin: `scala3-migrate`), then switch. LTS gets long backports and binary stability. ([source](https://www.scala-lang.org/download/all.html))
- **`SCALA-TOOL-02`** (SHOULD) Install toolchains with Coursier (`cs setup`) or sdkman/mise; use JDK 21 or 25 LTS (Temurin). Do not run on JDK < 17. Virtual threads and modern GC need 21+. ([source](https://get-coursier.io/docs/cli-installation))
- **`SCALA-TOOL-03`** (MUST) Format with scalafmt via `sbt-scalafmt`: check argv `sbt scalafmtCheckAll scalafmtSbtCheck`; fix `sbt scalafmtAll scalafmtSbt`; standalone `scalafmt --check`. One formatter, check-only in the gate. ([source](https://github.com/scalameta/sbt-scalafmt))
- **`SCALA-TOOL-04`** (SHOULD) Lint and refactor with scalafix (`sbt "scalafixAll --check"`) using `OrganizeImports`, `RemoveUnused`, `DisableSyntax` rules; keep `.scalafix.conf` in repo. scalafix semantic rules need `semanticdbEnabled := true` (automatic on Scala 3). Semantic rewrites beat regex. ([source](https://scalacenter.github.io/scalafix/))
- **`SCALA-TOOL-05`** (MUST) Use `sbt-tpolecat` (or `typelevel/sbt-tpolecat` `tpolecatDevModeOptions`/`tpolecatCiModeOptions`) so CI mode adds `-Werror`; at minimum set `-deprecation -feature -unchecked -Wunused:all -Wvalue-discard -Wnonunit-statement -Wconf:...`. Warnings must fail CI, not rot. ([source](https://docs.scala-lang.org/overviews/compiler-options/index.html))
- **`SCALA-TOOL-06`** (SHOULD) Scala 3 extra strictness: `-Wunused:all`, `-Wvalue-discard`, `-Wnonunit-statement`, `-source:future` on libraries you own, `-Yexplicit-nulls` only at Java boundaries, and `-language:strictEquality` for domain types. Opts into the strict dialect. ([source](https://docs.scala-lang.org/scala3/guides/migration/options-intro.html))
- **`SCALA-TOOL-07`** (SHOULD) Add WartRemover (`Wart.Null`, `Wart.Var`, `Wart.Return`, `Wart.AsInstanceOf`, `Wart.TryPartial`, `Wart.OptionPartial`, `Wart.Throw`) as errors in domain/application projects only; on Scala 3 use the versions that support it. Bans the partial functions that destroy totality. ([source](https://www.wartremover.org/doc/warts.html))
- **`SCALA-TOOL-08`** (MUST) Scan dependencies with OWASP `sbt-dependency-check` (`sbt dependencyCheck`; set `dependencyCheckFailBuildOnCVSS`) or OSV-Scanner against the dependency graph; generate an SBOM with `sbt-sbom` (CycloneDX: `sbt makeBom`). CVEs in transitive jars. ([source](https://github.com/albuch/sbt-dependency-check))
- **`SCALA-TOOL-09`** (SHOULD) Editor baseline: Metals (LSP, uses Bloop/BSP) with `metals.sbt` ignored; format-on-save must call the same `.scalafmt.conf`; disable Metals' "import build" prompt in CI. Metals writes `.bloop/`, `.metals/`, `.bsp/`. ([source](https://scalameta.org/metals/))

## ARCH - architecture
- **`SCALA-ARCH-01`** (SHOULD) Default to a modular monolith: one deployable, sbt subprojects per bounded context, hexagonal inside each. Split to services only on independent scaling/ownership. Use CQRS/event sourcing (Pekko Persistence, Akka-like, or Postgres event log with fs2) only where audit/replay is a requirement. Scala's type system makes module seams cheap; distributed systems are not. ([source](https://pekko.apache.org/docs/pekko/current/))
- **`SCALA-ARCH-02`** (MUST) The domain is plain Scala: `final case class`, `enum`/`sealed trait` ADTs, `opaque type` IDs, pure functions returning `Either`/`Option`. No `Future`, `IO`, `ZIO`, `Ref`, `Instant.now()`, `Random`, `scala.sys.env` in domain. Purity makes domain tests trivial and race-free. ([source](https://docs.scala-lang.org/scala3/reference/other-new-features/opaques.html))
- **`SCALA-ARCH-03`** (MUST) Ports are small traits owned by the consumer (application): `trait OrderRepo[F[_]] { def find(id: OrderId): F[Option[Order]] }` (tagless final) or `trait OrderRepo { def find(id: OrderId): IO[...] }` / `ZIO[Any, DbError, Option[Order]]` plus `ZLayer`. Adapters implement them. Consumer-owned ports, same as the loops rule. ([source](https://typelevel.org/cats-effect/docs/typeclasses))
- **`SCALA-ARCH-04`** (MUST) Choose ONE effect style per service. Tagless final (`F[_]: Async`) gives testability and abstraction at the cost of verbosity; concrete `IO` is simpler and usually enough; ZIO uses its environment/error channel. Do not mix `Future`, `IO` and `ZIO` in application code; convert at the edge (`IO.fromFuture`, `ZIO.fromFuture`). Mixed effects defeat cancellation and tests. ([source](https://typelevel.org/cats-effect/docs/getting-started))
- **`SCALA-ARCH-05`** (MUST) Dependency injection: manual wiring in `Main` using `Resource[IO, A]` (cats-effect) or `ZLayer` (ZIO); no runtime DI container, no reflection DI (Guice/MacWire only if Play forces it; prefer compile-time DI with `MacWire` or Play compile-time DI). Compile-time wiring is checked by scalac. ([source](https://typelevel.org/cats-effect/docs/std/resource))
- **`SCALA-ARCH-06`** (SHOULD) ZLayer vs sbt: one `ZLayer` per adapter project (`DbLive.layer`), assembled with `++`/`>>>` only in `app`; keep `*Live` (real) and `*Test` (fake) layers in different projects/configs. Tagless final equivalent: adapters expose `def make[F[_]: Async](cfg): Resource[F, OrderRepo[F]]`. The sbt graph then equals the layer graph. ([source](https://zio.dev/reference/contextual/zlayer))
- **`SCALA-ARCH-07`** (MUST) Visibility: use `private`, `private[pkg]`, `protected`, and `export`/`package-private` in Scala 3 to hide internals; mark all non-extension classes `final`; `sealed` for ADTs so `match` is exhaustive. Cycles between packages compile in one project, so enforce acyclicity with sbt subprojects, not packages. Scala does not forbid package cycles. ([source](https://docs.scala-lang.org/style/declarations.html))
- **`SCALA-ARCH-08`** (MUST) Package-to-directory mapping and imports: `package a.b` lives in `a/b` by convention (not enforced); imports are `import a.b.C`, `import a.b.{C, D as E}`, `import a.b.*` (Scala 3) / `import a.b._` (Scala 2), `import a.b.{given, *}`. The arch checker must parse these forms and map them to subprojects via the `package-dir` resolver. Scala packages need not match dirs, so the checker must read `package` clauses too. ([source](https://docs.scala-lang.org/scala3/reference/contextual/given-imports.html))
- **`SCALA-ARCH-09`** (SHOULD) Enforce direction with (a) sbt `dependsOn` (compiler-enforced), (b) `sbt-sbtarch`/ArchUnit via `archunit` through JUnit for package rules, (c) scalafix `DisableSyntax`/`NoImports` or custom rule, (d) `loops arch`. Example ArchUnit: `noClasses().that().resideInAPackage("..domain..").should().dependOnClassesThat().resideInAnyPackage("..adapters..","..http4s..","..doobie..","cats.effect..","zio..")`. Package rules inside one project need a tool. ([source](https://www.archunit.org/userguide/html/000_Index.html))
- **`SCALA-ARCH-10`** (SHOULD) Value objects are `final case class`/`opaque type` with smart constructors returning `Either[DomainError, A]` (or refined types via `iron`/`refined`); entities carry an ID and do not rely on `equals`; aggregates are immutable with `copy`; domain events are `sealed trait`/`enum`. Illegal states become unrepresentable. ([source](https://github.com/Iltotore/iron))
- **`SCALA-ARCH-11`** (MUST) Actor model: use Pekko Typed (`org.apache.pekko`), not Akka (BSL since 2.7 and later, Change Date 2029 for 2.10.x, commercial licence for production), for stateful per-entity concurrency, clustering and streams; otherwise prefer cats-effect/fs2 or ZIO. Never share mutable state across actors. Akka's licence forbids free production use outside the Play grant. ([source](https://pekko.apache.org/))
- **`SCALA-ARCH-12`** (SHOULD) Size heuristics: file ≤ 400 lines, function ≤ 40 lines, ≤ 5 parameters (use a case class), traits ≤ 7 methods, one top-level public type per file (companions together). Matches loops SOLID limits in Scala units. ([source](https://docs.scala-lang.org/style/))

## IDIOM - what to do and what to avoid
- **`SCALA-IDIOM-01`** (MUST) Model expected failures as values: `Either[DomainError, A]` with a `sealed` error ADT; reserve exceptions for bugs and Java interop. Effect error channel: `IO` with `MonadError`, ZIO's `E`. Never `throw` in domain, never `catch Throwable` (use `NonFatal`). Total functions, exhaustive matches. ([source](https://docs.scala-lang.org/style/))
- **`SCALA-IDIOM-02`** (MUST) Never use `null`; use `Option`. Wrap Java returns at the boundary with `Option(x)`. Use `-Yexplicit-nulls` for Java-heavy modules. Never call `.get` on `Option`/`Try`/`Either`. NPEs and partial functions. ([source](https://docs.scala-lang.org/scala3/reference/experimental/explicit-nulls.html))
- **`SCALA-IDIOM-03`** (MUST) Immutable by default: `val` over `var`, immutable collections (`scala.collection.immutable`), `final case class` + `copy`; no `var` or `return`. Mutable state only inside `Ref`/`AtomicReference`/`TrieMap` at the edge. Removes shared-mutable-state races. ([source](https://docs.scala-lang.org/style/))
- **`SCALA-IDIOM-04`** (SHOULD) Scala 3: `enum` for ADTs, `given`/`using` instead of implicits, `extension` methods, `opaque type`, union/intersection types with restraint; Scala 2 code: avoid implicit conversions. Use exhaustive pattern matching and let `-Wunused`/exhaustivity warnings fail the build. Idiomatic and safer. ([source](https://docs.scala-lang.org/scala3/reference/))
- **`SCALA-IDIOM-05`** (MUST) Acquire resources with `Resource.make`/`Resource.fromAutoCloseable` (cats-effect), `ZIO.acquireRelease`/`ZLayer.scoped` (ZIO), or `scala.util.Using` for synchronous code. Never call `close()` manually in finally outside those. Leaked connections/fibers. ([source](https://typelevel.org/cats-effect/docs/std/resource))
- **`SCALA-IDIOM-06`** (SHOULD) Equality: `case class` auto-generates `equals`; do not override on mutable fields; enable `-language:strictEquality` and `derives CanEqual`; use `cats.Eq` for typed comparison. Time: `java.time` only; inject `Clock[F]`/`zio.Clock`; store `Instant` UTC; never `java.util.Date`. Multiversal equality catches `Int == String`. ([source](https://docs.scala-lang.org/scala3/reference/contextual/multiversal-equality.html))
- **`SCALA-IDIOM-07`** (SHOULD) Naming: `UpperCamelCase` types, `lowerCamelCase` values, `UPPER_SNAKE` only for Java-style constants, packages lowercase; omit `get` prefixes; use parameterless methods without parens for accessors; no symbolic method names except DSL operators. Format with scalafmt; two-space indent (Scala 3 braces optional: pick `significantIndentation` consistently). Official style guide. ([source](https://docs.scala-lang.org/style/naming-conventions.html))
- **`SCALA-IDIOM-08`** (AVOID) Metaprogramming: prefer `derives`, `inline` and Mirror-based derivation over reflection; macros only in libraries; no runtime reflection and no `scala.reflect` in services. Avoid annotation-heavy frameworks. Compile-time derivation is checked and AOT-friendly. ([source](https://docs.scala-lang.org/scala3/guides/macros/index.html))
- **`SCALA-IDIOM-09`** (AVOID) Avoid implicit conversions and `implicit` parameters with default types such as `ExecutionContext` in public APIs; pass them explicitly or via `given` with a name. Implicit resolution surprises. ([source](https://docs.scala-lang.org/scala3/reference/contextual/conversions.html))
- **`SCALA-IDIOM-10`** (AVOID) Avoid `Await.result`, `Future.apply` in hot paths, `Thread.sleep`, and `scala.concurrent.blocking` in effect code. Use `IO.sleep`/`ZIO.sleep`. Blocks the compute pool. ([source](https://typelevel.org/cats-effect/docs/thread-model))
- **`SCALA-IDIOM-11`** (AVOID) Avoid `Any`/`AnyRef`-typed collections, `asInstanceOf`, `isInstanceOf`, `Try` as a domain error type, and `@SuppressWarnings` without a ticket. Type erasure and warnings suppression. ([source](https://www.wartremover.org/doc/warts.html))
- **`SCALA-IDIOM-12`** (AVOID) Avoid parallel collections and deep `for`-comprehension nests in application logic; use `traverse`/`parTraverse`/`ZIO.foreachPar`. Do not use `.par`. Hidden thread pools. ([source](https://typelevel.org/cats/typeclasses/traverse.html))

## CONC - concurrency and the `-race` equivalent

**Loops race policy: `mode = none`. There is no general data-race detector for the JVM.** Substitute enforced by loops: run the test task with suites in parallel (`Test / parallelExecution` is already true by default; if `Test / fork := true`, also set `Test / testForkedParallel := true`, since forked tests run sequentially otherwise) and have loops repeat the whole test command 3 times itself (three sequential invocations of the same argv, e.g. `sbt -batch 'set Test / testForkedParallel := true' test`) (`-repeat` in ZIO Test via `TestAspect.nonFlaky`/`repeats`; cats-effect via `TestControl`), with randomised order where the framework allows it. jcstress and Lincheck are optional per-project tools, not gate checks.

- **`SCALA-CONC-01`** (MUST) Model: JVM threads (platform and Loom virtual threads on JDK 21+), cats-effect fibers on a work-stealing `IORuntime`, ZIO fibers on ZIO's executor, Pekko actors; Scala `Future` is eager and uncancellable and is the legacy option. Each model has its own cancellation and blocking rules. ([source](https://typelevel.org/cats-effect/docs/concepts))
- **`SCALA-CONC-02`** (MUST) Share state only via `Ref`/`Ref.Make`, `AtomicCell`, `Semaphore`, `Queue`, `Deferred` (cats-effect), `Ref`/`Queue`/`Promise`/`STM`/`TRef` (ZIO), or message passing (Pekko). Never mutate `var`/`mutable.Map` from fibers; do not read-modify-write with `get` then `set` (use `update`/`modify`). Fibers run on multiple threads. ([source](https://typelevel.org/cats-effect/docs/std/ref))
- **`SCALA-CONC-03`** (MUST) Race detection: none for JVM. Static aids: `-Wnonunit-statement` (finds dropped effects), scalafix `DisableSyntax`; dynamic aids: jcstress (OpenJDK) for lock-free code, Lincheck for linearizability, ThreadSanitizer is not for the JVM; effect-system aids: cats-effect `TestControl` (virtual-time mock runtime, not deterministic: it picks among pending fibers at random), ZIO `TestClock`. State the limitation honestly. ([source](https://github.com/openjdk/jcstress))
- **`SCALA-CONC-04`** (MUST) Loops substitute for race: (1) tests run with suite parallelism (default; with `fork := true` add `Test / testForkedParallel := true`), (2) the gate itself invokes the test command 3 times (loops loop, not an sbt feature), (3) any `Ref`/`STM`/fiber code has a concurrent test using `parTraverse`/`ZIO.foreachPar` with ≥100 iterations, (4) tests use virtual time not `sleep`. Probabilistic but cheap. ([source](https://zio.dev/reference/test/aspects/))
- **`SCALA-CONC-05`** (MUST) Async pitfalls: never block a compute thread (wrap in `IO.blocking`/`ZIO.attemptBlocking`), always set timeouts (`.timeout`), make cancellation safe (`uncancelable`/`bracket`), bound queues for backpressure, and never fire-and-forget `.start`/`fork` without supervision (use `Supervisor`/`Scope`). Unhandled errors in forked fibers are silent, so join or log them. Fiber leaks. ([source](https://typelevel.org/cats-effect/docs/std/supervisor))
- **`SCALA-CONC-06`** (SHOULD) Streams: use fs2 or ZIO Streams or Pekko Streams with bounded buffers; `parEvalMap(n)`, `mapAsync(n)`; handle backpressure by design. Unbounded memory. ([source](https://fs2.io/))
- **`SCALA-CONC-07`** (MUST) Background work: dedicated `Resource`-managed worker fibers, `Supervisor`, schedule with `fs2.Stream.awakeEvery` or `Schedule`; graceful shutdown on SIGTERM by running `Main` as `IOApp`/`ZIOAppDefault`, which cancels the main fiber and runs finalizers. Use Quartz/Pekko Scheduler only if persistence of schedules is needed. Finalizers run on cancel. ([source](https://typelevel.org/cats-effect/docs/core/io-runtime-config))

## TEST - testing

**Coverage recipe:** scoverage via `sbt-scoverage`; format Cobertura XML (plus `scoverage.xml`); argv `sbt -batch clean coverage test coverageReport` (add `coverageAggregate` for multi-project); output `target/scala-<full scala version>/coverage-report/cobertura.xml` per subproject (aggregate: root `target/scala-<ver>/coverage-report/`; `scoverage.xml` and HTML go to `scoverage-report/`); statement + branch coverage; new-code coverage: loops computes it by intersecting changed lines (git diff against base) with `<class filename=... ><line number hits>` entries; `diff-cover` also reads Cobertura XML. On sbt 2 the target dir moves, so resolve by `show coverageDataDir`/glob.

- **`SCALA-TEST-01`** (SHOULD) Unit framework: MUnit by default (simple, JUnit-compatible, `CatsEffectSuite` via munit-cats-effect, ScalaCheck via `ScalaCheckSuite`); ScalaTest for existing codebases or BDD style; weaver-test for cats-effect-native, parallel-by-default suites; ZIO Test for ZIO. Pick one per project. One style, one runner. ([source](https://scalameta.org/munit/))
- **`SCALA-TEST-02`** (MUST) Layout: `src/test/scala` mirrors main packages; unit tests `*Spec.scala`, `*Suite.scala` or `*Test.scala`; integration tests in an `it` subproject (`it/src/test/scala`, `IntegrationTest` config is deprecated, so use a separate project with `dependsOn(app % "test->test")`). Test globs: `**/src/test/scala/**/*.scala`, `**/*Spec.scala`, `**/*Suite.scala`, `**/*Test.scala`, `**/*Spec.sc`. Loops needs to know what is a test. ([source](https://www.scala-sbt.org/1.x/docs/Testing.html))
- **`SCALA-TEST-03`** (SHOULD) Style: arrange-act-assert, names as sentences (`test("rejects an expired token")`), parametrise with loops/`List.foreach` in MUnit, `forAll`/`TableDrivenPropertyChecks` in ScalaTest, `Gen` in ZIO Test. Readable failures. ([source](https://scalameta.org/munit/docs/tests.html))
- **`SCALA-TEST-04`** (SHOULD) Test doubles: hand-written fakes of the port trait/`ZLayer` (in-memory `Ref`-backed repos); Mockito-scala/MockitoSugar only for third-party Java types; never mock the domain. Fakes survive refactors. ([source](https://zio.dev/reference/test/))
- **`SCALA-TEST-05`** (SHOULD) Integration tests use `testcontainers-scala` (`TestContainerForAll` / `munit-testcontainers`) with a real Postgres/Kafka and a fresh schema per suite via Flyway; clean per test with transactions or truncation. Requires Docker: gate marks these tests so they can be skipped when Docker is unavailable. Real SQL dialects. ([source](https://github.com/testcontainers/testcontainers-scala))
- **`SCALA-TEST-06`** (MUST) Coverage: `sbt -batch clean coverage test coverageReport`; set `coverageFailOnMinimum := true`, `coverageMinimumStmtTotal := 70`, `coverageMinimumBranchTotal := 60`; exclude generated code with `coverageExcludedPackages := "<empty>;.*\\.generated\\..*;.*BuildInfo.*"` and `coverageExcludedFiles` (Scala 3.3.4+ / 3.4.2+; comment markers `$COVERAGE-OFF$` work only on Scala 2). ## SEC - security
- **`SCALA-SEC-01`** (MUST) SQL: never build SQL with string interpolation `s"..."` or `+`; use doobie `fr"..."`/`sql"..."` interpolators (parameters become bind variables, `Fragment.const` only for trusted identifiers), skunk `sql"..."` with codecs, Slick `sql"..."`/`#$` only for trusted identifiers, Quill quotations. Commands: use `ProcessBuilder(Seq(...))`, never a single shell string. Typed interpolators parameterise. ([source](https://cheatsheetseries.owasp.org/cheatsheets/SQL_Injection_Prevention_Cheat_Sheet.html))
- **`SCALA-SEC-02`** (MUST) Deserialisation: never use Java serialization (`ObjectInputStream`), Kryo with open class registration, or Jackson default typing; use circe/jsoniter-scala/zio-json/Tapir codecs with sealed ADTs; configure XML parsers against XXE (`disallow-doctype-decl`). JVM deserialisation gadgets. ([source](https://cheatsheetseries.owasp.org/cheatsheets/Deserialization_Cheat_Sheet.html))
- **`SCALA-SEC-03`** (MUST) Web: SSRF allow-list outbound URLs, normalise paths (`os.Path`/`java.nio.file.Path.normalize` then check prefix), CORS explicit origins (http4s `CORS` middleware, Play filters), CSRF tokens for cookie auth (Play CSRF filter, http4s `CSRF`), security headers middleware. OWASP A01/A10. ([source](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html))
- **`SCALA-SEC-04`** (MUST) Secrets from env or vault, loaded with Ciris/PureConfig into a case class with a `Secret` wrapper (redacting `toString`); no secrets in `application.conf`; passwords hashed with Argon2id/bcrypt (BouncyCastle or Spring Security Crypto), randomness via `SecureRandom`, TLS via JDK defaults; do not use `MD5`/`SHA1`/`java.util.Random`/DES. Standard crypto hygiene. ([source](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html))
- **`SCALA-SEC-05`** (MUST) Validate at the boundary: decode DTOs with circe/zio-json/Tapir, then convert into domain types via smart constructors (`Either`) or refined/iron types; reject unknown fields where appropriate (`Configuration.default.withStrictDecoding`). Parse, don't validate. ([source](https://tapir.softwaremill.com/en/latest/endpoint/validation.html))
- **`SCALA-SEC-06`** (MUST) Supply chain: trust only Maven Central/Sonatype and an internal mirror; Coursier verifies checksums; enable sbt `updateOptions` and `sbt-dependency-check`; pin sbt plugin versions in `project/plugins.sbt` since plugins run arbitrary code at build time; review Scala Steward PRs. sbt plugins execute code. ([source](https://www.scala-sbt.org/1.x/docs/Resolvers.html))
- **`SCALA-SEC-07`** (SHOULD) SAST: Semgrep with the Scala ruleset; scalac security via WartRemover; `sbt-scala-security`/find-sec-bugs works on bytecode (`sbt-findbugs` scala support is limited), so combine with CodeQL (Scala via Java/Kotlin extractor limited) and Semgrep. No dominant Scala SAST. ([source](https://semgrep.dev/docs/supported-languages/))

## Top 10 footguns

1. **Blocking the compute pool.** Bad: `IO(blockingJdbc())` / `Await.result`. Fix: `IO.blocking(...)`, `ZIO.attemptBlocking`, or a dedicated pool. ([cats-effect thread model](https://typelevel.org/cats-effect/docs/thread-model))
2. **Dropped effects.** Bad: a statement `logger.info("x")` returning `IO` that is never run. Fix: `-Wnonunit-statement` plus `-Wvalue-discard` as errors. ([scalac options](https://docs.scala-lang.org/overviews/compiler-options/index.html))
3. **Read-modify-write on `Ref`.** Bad: `ref.get.flatMap(v => ref.set(v + 1))`. Fix: `ref.update(_ + 1)` or `modify`. ([Ref](https://typelevel.org/cats-effect/docs/std/ref))
4. **Fire-and-forget fibers.** Bad: `io.start` never joined or cancelled. Fix: `Supervisor`, `background`, `Scope`. ([Supervisor](https://typelevel.org/cats-effect/docs/std/supervisor))
5. **`Option.get` / `null` / `asInstanceOf`.** Fix: pattern match, `fold`, WartRemover `Wart.OptionPartial`, `Wart.Null`. ([WartRemover](https://www.wartremover.org/doc/warts.html))
6. **Wrong `%` vs `%%`.** Bad: `"org.typelevel" % "cats-core" % "2.13.0"`. Fix: `%%`, so the Scala binary suffix is added. ([sbt library deps](https://www.scala-sbt.org/1.x/docs/Library-Dependencies.html))
7. **Eager `Future`.** Bad: `val f = Future(sideEffect())` at class init runs immediately and cannot be cancelled. Fix: `IO`/`ZIO` (lazy, cancelable) or a `def`. ([cats-effect](https://typelevel.org/cats-effect/docs/getting-started))
8. **Stale scoverage instrumentation.** Bad: `sbt coverage test` without `clean`. Fix: `sbt clean coverage test coverageReport`, then `coverageOff`. ([sbt-scoverage](https://github.com/scoverage/sbt-scoverage))
9. **Implicit ambiguity and auto-derivation.** Bad: `io.circe.generic.auto._` in a large module (slow compile, wrong codecs). Fix: `derives Codec.AsObject` / `semiauto`. ([circe](https://circe.github.io/circe/))
10. **Using Akka for a new project.** Bad: `akka-actor` 2.7+ (BSL). Fix: Apache Pekko. ([Akka licences](https://doc.akka.io/libraries/akka-core/current/project/licenses.html))
