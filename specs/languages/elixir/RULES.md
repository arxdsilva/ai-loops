# Elixir rules

Backend rule book for Elixir `1.20` (1.19 supported) on Erlang/OTP 27-29, as of 2026-11. Derived from `research/languages/elixir.md` (verified, round 2); rule IDs are kept so the trace holds. Universal rules are not restated: see `specs/ARCHITECTURE.md` and `specs/SOLID.md`. Project rules win over everything here; log each override with `loops run override`. Pack: `specs/languages/elixir/pack.json`.

Format: `ID (severity) rule. Why. (source)`. Hex docs hosts are `<pkg>.hexdocs.pm`.

## REPO
- **`ELIXIR-REPO-01`** (MUST) One Mix project: `lib/<app>/` (core) and `lib/<app>_web/` (web); tests in `test/` mirroring `lib/`, files `*_test.exs`, helpers in `test/support/` compiled only in `:test` via `elixirc_paths(:test)`. Every tool assumes this layout. ([Mix.Tasks.Test](https://mix.hexdocs.pm/Mix.Tasks.Test.html))
- **`ELIXIR-REPO-02`** (SHOULD) Start services from `mix phx.new` or `mix new NAME --sup`; plain `mix new` has no supervisor. ([Mix.Tasks.New](https://mix.hexdocs.pm/Mix.Tasks.New.html))
- **`ELIXIR-REPO-03`** (SHOULD) Default to a single project; use an umbrella only for independent deploys or dependency sets, with `in_umbrella: true` deps. Umbrellas share one lock and add config/CI cost; Boundary covers a modular monolith. ([Mix.Tasks.New](https://mix.hexdocs.pm/Mix.Tasks.New.html))
- **`ELIXIR-REPO-04`** (MUST) Commit `mix.lock` for applications; libraries commit it for dev only (Hex excludes it). Never hand-edit it; use `mix deps.update`. ([Deps.Get](https://mix.hexdocs.pm/Mix.Tasks.Deps.Get.html))
- **`ELIXIR-REPO-05`** (SHOULD) Pin with `~>`; CI runs `mix deps.get --check-locked` and `mix deps.unlock --check-unused`; drop dead deps with `mix deps.clean --unlock --unused`. ([Deps.Unlock](https://mix.hexdocs.pm/Mix.Tasks.Deps.Unlock.html))
- **`ELIXIR-REPO-06`** (SHOULD) Automate updates with Dependabot (`package-ecosystem: "mix"`, version updates only) or Renovate; for advisories rely on `mix deps.audit` and `mix hex.audit`. ([Dependabot](https://docs.github.com/en/code-security/dependabot/ecosystems-supported-by-dependabot/supported-ecosystems-and-repositories))
- **`ELIXIR-REPO-07`** (SHOULD) SemVer; a Hex package needs `package/0`, `@version` and a clean `mix hex.build`; services ship as releases tagged `v<version>`, not published. ([Hex.Publish](https://hex.hexdocs.pm/Mix.Tasks.Hex.Publish.html))
- **`ELIXIR-REPO-08`** (MUST) Pin the toolchain in `.tool-versions` (asdf or mise) with the OTP major (`elixir 1.20.5-otp-28`, `erlang 28.x`), mirror it in CI and the Dockerfile, set `elixir: "~> 1.19"` in `mix.exs`. Formatter output and type warnings vary by version. ([asdf-elixir](https://github.com/asdf-vm/asdf-elixir), [mise](https://mise.jdx.dev/lang/elixir.html))
- **`ELIXIR-REPO-09`** (MUST) Ignore `/_build/`, `/deps/`, `/cover/`, `/doc/`, `erl_crash.dump`, `*.ez`, `/priv/plts/*.plt*`, `/tmp/`, `.elixir_ls/`, `.lexical/`, `*.beam`; commit `.formatter.exs`, `.credo.exs`, `coveralls.json`, `.sobelow-conf`. ([Dialyxir](https://github.com/jeremyjh/dialyxir))
- **`ELIXIR-REPO-10`** (MUST) CI order: deps (cached on `mix.lock` + `.tool-versions`), `mix format --check-formatted`, `mix compile --warnings-as-errors`, `mix credo --strict`, `mix dialyzer`, `mix test` with coverage, `mix deps.audit` + `mix hex.audit`, `mix sobelow --exit medium`, `mix release`. Matrix over Elixir/OTP only for libraries. ([Mix.Tasks.Compile](https://mix.hexdocs.pm/Mix.Tasks.Compile.html))
- **`ELIXIR-REPO-11`** (SHOULD) Conventional commits; libraries keep `CHANGELOG.md`; bump `@version` in `mix.exs` only and tag `v<version>` from it. ([Conventional Commits](https://www.conventionalcommits.org/))

## TOOL
- **`ELIXIR-TOOL-01`** (MUST) Target Elixir 1.19/1.20 on OTP 27/28/29. 1.20 needs OTP 27-29 (bug fixes); 1.19 needs 26-28 and requires OTP 28.1+ on 28; 1.18 gets security fixes only. ([compatibility](https://elixir.hexdocs.pm/compatibility-and-deprecations.html), [v1.20](https://elixir-lang.org/blog/2026/06/03/elixir-v1-20-0-released/))
- **`ELIXIR-TOOL-02`** (SHOULD) Use asdf, mise or the `hexpm/elixir` image; never the distro package (old minors, arbitrary OTP). ([asdf-elixir](https://github.com/asdf-vm/asdf-elixir))
- **`ELIXIR-TOOL-03`** (MUST) Format with `mix format`, configured in `.formatter.exs` (`inputs`, `import_deps`, `plugins`, `line_length`). CI: `mix format --check-formatted`; one file: `mix format <file>`. ([Mix.Tasks.Format](https://mix.hexdocs.pm/Mix.Tasks.Format.html))
- **`ELIXIR-TOOL-04`** (SHOULD) Run `mix credo --strict`; commit `.credo.exs` (`mix credo gen.config`). ([Credo](https://credo.hexdocs.pm/Mix.Tasks.Credo.html))
- **`ELIXIR-TOOL-05`** (MUST) Warnings are errors: `mix compile --warnings-as-errors`, `mix test --warnings-as-errors` (exit 1 when the suite would otherwise pass, `--exit-status`+1, default 3, when tests also fail). The compiler type system reports real bugs as warnings. ([Mix.Tasks.Test](https://mix.hexdocs.pm/Mix.Tasks.Test.html))
- **`ELIXIR-TOOL-06`** (MUST) Type checking is the compiler's gradual set-theoretic system (1.17+, inference of all constructs in 1.20; no signatures yet). Fix the warning, do not work around it; `@spec` + Dialyzer are an optional second layer. ([v1.20](https://elixir-lang.org/blog/2026/06/03/elixir-v1-20-0-released/), [types](https://elixir.hexdocs.pm/gradual-set-theoretic-types.html))
- **`ELIXIR-TOOL-07`** (SHOULD) Dialyzer via `{:dialyxir, "~> 1.4", only: [:dev, :test], runtime: false}`; cache the PLT (`plt_file: {:no_warn, "priv/plts/project.plt"}`); ignores in `.dialyzer_ignore.exs`. Optional: the first PLT build takes minutes. ([Dialyxir](https://github.com/jeremyjh/dialyxir))
- **`ELIXIR-TOOL-08`** (MUST) Scan dependencies with `mix deps.audit` (mix_audit `~> 2.1`) and `mix hex.audit` (retired packages and advisories; `ignore_advisories` for accepted risk). ([mix_audit](https://github.com/mirego/mix_audit), [Hex.Audit](https://hex.hexdocs.pm/Mix.Tasks.Hex.Audit.html))
- **`ELIXIR-TOOL-09`** (SHOULD) SBOM with the `sbom` package (`mix sbom.cyclonedx`); check licences from package metadata. ([sbom](https://hex.pm/packages/sbom))
- **`ELIXIR-TOOL-10`** (SHOULD) Editor: Expert (official LSP), ElixirLS or Lexical; format-on-save through `mix format` only. ([Expert](https://github.com/expert-lsp/expert))

## ARCH
- **`ELIXIR-ARCH-01`** (SHOULD) Pick the style by size: Phoenix contexts for CRUD-heavy apps; hexagonal (behaviour ports, Ecto only in adapters) for rich domains or several I/O boundaries; Boundary-checked modular monolith before microservices; CQRS/ES (Commanded) only with proven need. See `specs/ARCHITECTURE.md`. ([contexts](https://phoenix.hexdocs.pm/contexts.html))
- **`ELIXIR-ARCH-02`** (MUST) `lib/<app>/` never references `Phoenix.*`, `Plug.*` or `<App>Web.*`; web calls the context API, never `Repo` or schemas. See `specs/ARCHITECTURE.md` §3. ([Boundary](https://boundary.hexdocs.pm/Boundary.html))
- **`ELIXIR-ARCH-03`** (MUST) One module per file; `Foo.Bar` lives at `lib/foo/bar.ex`. Dependencies arrive via `alias` (also grouped `{A, B}`), `import`, `require`, `use` and fully qualified calls. Public by default: mark internals `defp` or `@moduledoc false`. Cycles cause recompilation chains. ([Xref](https://mix.hexdocs.pm/Mix.Tasks.Xref.html))
- **`ELIXIR-ARCH-04`** (MUST) Enforce layers with Boundary 0.12: `compilers: [:boundary] ++ Mix.compilers()`, `use Boundary, deps:, exports:` in each context root; violations are compile warnings, caught by `--warnings-as-errors`. ([Boundary](https://boundary.hexdocs.pm/Boundary.html))
- **`ELIXIR-ARCH-05`** (SHOULD) Also gate cycles: `mix xref graph --format cycles --fail-above 0` (`--label compile-connected` for recompile health; `--source/--sink` to explain). ([Xref](https://mix.hexdocs.pm/Mix.Tasks.Xref.html))
- **`ELIXIR-ARCH-06`** (SHOULD) Wire dependencies in `Application.start/2` (child specs) and `config/runtime.exs` (adapter per environment). Read config once or pass arguments; no `Application.get_env` deep in the domain, no `compile_env` for per-request choices. See `specs/ARCHITECTURE.md` §21. ([Application](https://elixir.hexdocs.pm/Application.html), [anti-patterns](https://elixir.hexdocs.pm/design-anti-patterns.html))
- **`ELIXIR-ARCH-07`** (MUST) Keep the domain pure: no `Repo`, `File`, `System`, `Logger`, `DateTime.utc_now`, `:rand`/`Enum.random`, `Process`/`Task`/`send`, `:ets`. Inject time, ids and randomness (`Clock`/`IdGenerator` behaviours). Return tagged tuples. See `specs/ARCHITECTURE.md` §20. ([library guidelines](https://elixir.hexdocs.pm/library-guidelines.html))
- **`ELIXIR-ARCH-08`** (SHOULD) Ports are `@behaviour` + `@callback` owned by the consumer context; adapters use `@impl true`; doubles via `Mox.defmock(..., for: Behaviour)`. Few callbacks per behaviour. ([Mox](https://mox.hexdocs.pm/Mox.html))
- **`ELIXIR-ARCH-09`** (MUST) No process for code organisation: `GenServer`/`Agent`/`Task` only for mutable runtime state, concurrency or failure isolation; plain modules otherwise. One API module wraps each process. ([process anti-patterns](https://elixir.hexdocs.pm/process-anti-patterns.html))
- **`ELIXIR-ARCH-10`** (SHOULD) Short multi-clause functions; at most 5 parameters (else keyword list or struct); structs under 32 fields; no `with` with complex `else`. See `specs/SOLID.md`. ([code anti-patterns](https://elixir.hexdocs.pm/code-anti-patterns.html))
- **`ELIXIR-ARCH-11`** (SHOULD) Phoenix 1.8: pass a `scope` struct first to every context function and filter by it; never read the user/org from process state. ([scopes](https://phoenix.hexdocs.pm/scopes.html))

## IDIOM
- **`ELIXIR-IDIOM-01`** (MUST) Expected failures return `{:ok, v}`/`{:error, reason}`; raise only for programmer errors; offer `foo/1` and `foo!/1`. No exceptions as control flow. ([design anti-patterns](https://elixir.hexdocs.pm/design-anti-patterns.html))
- **`ELIXIR-IDIOM-02`** (MUST) Let it crash: no broad `rescue`/`catch` that hides failure; handle what you can act on and let supervisors restart the rest. Never `rescue _` without re-raise or logging. ([Supervisor](https://elixir.hexdocs.pm/Supervisor.html))
- **`ELIXIR-IDIOM-03`** (SHOULD) Normalise error shapes in small private functions; prefer `{:error, %MyApp.Error{}}` or atoms like `:not_found` over strings. ([code anti-patterns](https://elixir.hexdocs.pm/code-anti-patterns.html))
- **`ELIXIR-IDIOM-04`** (MUST) Be assertive: `Map.fetch/2`, `map.key` for required keys, `map[:key]` for optional; no truthiness on non-booleans; `and`/`or`/`not` for booleans. ([code anti-patterns](https://elixir.hexdocs.pm/code-anti-patterns.html))
- **`ELIXIR-IDIOM-05`** (SHOULD) Model values with structs (`defstruct`, `@enforce_keys`) and `%{s | k: v}`; do not mix maps and structs for one concept; avoid primitive obsession. ([design anti-patterns](https://elixir.hexdocs.pm/design-anti-patterns.html))
- **`ELIXIR-IDIOM-06`** (SHOULD) Pattern matching and multi-clause functions with guards; no catch-all `_` clauses that mask new cases. ([code anti-patterns](https://elixir.hexdocs.pm/code-anti-patterns.html))
- **`ELIXIR-IDIOM-07`** (SHOULD) `@spec` on public functions, `@type`/`@typep` for data, `@behaviour` + `@impl true`. The compiler does not read specs; Dialyzer does. ([typespecs](https://elixir.hexdocs.pm/typespecs.html))
- **`ELIXIR-IDIOM-08`** (MUST) Resources: `File.open/2` with a function or `try ... after`; supervisors for long-lived processes; `Task.Supervisor` for fire-and-forget; link or monitor everything spawned; pool and close handles. ([Task.Supervisor](https://elixir.hexdocs.pm/Task.Supervisor.html))
- **`ELIXIR-IDIOM-09`** (SHOULD) Strings are UTF-8 binaries: `String.*` for text (grapheme-aware), iodata in hot paths. `DateTime` in UTC with a tz database; no `NaiveDateTime` for instants; no floats for money (`Decimal`). ([library guidelines](https://elixir.hexdocs.pm/library-guidelines.html))
- **`ELIXIR-IDIOM-10`** (SHOULD) `snake_case` functions, `CamelCase` modules, `?` for booleans, `is_` for guards, `!` for raising; library modules carry the library prefix. Order: `@moduledoc`, `@behaviour`, `use`, `import`, `require`, `alias`, attributes, `defstruct`, `@type`, `@callback`. ([style guide](https://github.com/christopheradams/elixir_style_guide))
- **`ELIXIR-IDIOM-11`** (AVOID) Macros unless a function cannot do it; `use` with a small explicit `__using__`; never create atoms from external input. ([code anti-patterns](https://elixir.hexdocs.pm/code-anti-patterns.html), [EEF hardening](https://security.erlef.org/secure_coding_and_deployment_hardening/))
- **`ELIXIR-IDIOM-12`** (SHOULD) `Enum`/`Stream` pipelines; `|>` for chains of two or more calls starting from a bare value, never one pipe; `Stream`/`Flow` only for large or lazy data. ([style guide](https://github.com/christopheradams/elixir_style_guide))

## CONC
Policy: `race.mode = none` (no sanitizer; BEAM processes share no memory). The gate runs `mix test --repeat-until-failure 5 --warnings-as-errors`, required, with async modules and the printed seed.
- **`ELIXIR-CONC-01`** (MUST) Isolated processes with private heaps, preemptive scheduling, message passing, links and monitors. One process per unit of concurrent state or fault domain (session, aggregate), not per function. ([OTP design](https://erlang.org/doc/system/design_principles.html))
- **`ELIXIR-CONC-02`** (SHOULD) Share state by messaging: `Agent`/`GenServer` for small state, `Registry` for lookup, `Task`/`Task.Supervisor` for work, `DynamicSupervisor` for per-entity processes, `:ets` or `:persistent_term` for read-heavy data. Choose the smallest. ([Registry](https://elixir.hexdocs.pm/Registry.html))
- **`ELIXIR-CONC-03`** (MUST) Logical races remain: check-then-act across two calls, ETS read-modify-write on `:public` tables (use `update_counter`/`insert_new`/`select_replace` or one owner), ordering guaranteed only per sender-receiver pair, `Registry.lookup` then `call` on a dead pid. Make operations atomic in one process or one transaction. ([Registry](https://elixir.hexdocs.pm/Registry.html))
- **`ELIXIR-CONC-04`** (MUST) Race substitute: async modules by default (random order, `--max-cases` default 2x cores), `mix test --repeat-until-failure 5` in the gate, printed seed, re-run failures with `--seed N`. Concuerror is stale (last release 2020) and advisory only. ([Mix.Tasks.Test](https://mix.hexdocs.pm/Mix.Tasks.Test.html))
- **`ELIXIR-CONC-05`** (MUST) Deliberate `GenServer.call` timeouts (default 5000 ms, caller exits); never block in `init/1` (use `handle_continue/2`); no own `receive` in callbacks; no cleanup reliance on `terminate/2`. ([GenServer](https://elixir.hexdocs.pm/GenServer.html))
- **`ELIXIR-CONC-06`** (SHOULD) Do not send large terms (extract `conn.remote_ip`, not `conn`); bound mailboxes with backpressure (GenStage, Broadway, Oban queues) or `:max_heap_size`. ([process anti-patterns](https://elixir.hexdocs.pm/process-anti-patterns.html))
- **`ELIXIR-CONC-07`** (SHOULD) Background work: Oban for durable jobs, `Task.Supervisor.async_nolink` for in-memory, Broadway for ingestion; releases stop apps in reverse start order on SIGTERM. ([Oban](https://oban.hexdocs.pm/Oban.html))
- **`ELIXIR-CONC-08`** (SHOULD) Supervision: children in dependency order; `:one_for_one` by default, `:rest_for_one` for ordered dependencies; tune `max_restarts`/`max_seconds`; separate error-kernel supervisors from workers. ([sup principles](https://www.erlang.org/doc/system/sup_princ.html))
- **`ELIXIR-CONC-09`** (AVOID) Pools of GenServers to limit concurrency and global GenServers as lanes: Phoenix/Bandit already isolate each request. Not for pure logic, config lookup or serialising CPU work. ([GenServer](https://elixir.hexdocs.pm/GenServer.html))

## TEST
Coverage: `excoveralls`, format lcov, `MIX_ENV=test mix coveralls.lcov` to `cover/lcov.info` (line granularity, absolute `SF:` paths). Built-in `mix test --cover` writes no lcov.
- **`ELIXIR-TEST-01`** (MUST) ExUnit with `ExUnit.start()` in `test/test_helper.exs`; `Phoenix.ConnTest`/`Plug.Test` for HTTP, `Phoenix.LiveViewTest` for LiveView; doctests via `doctest MyApp.Mod`. ([ExUnit.Case](https://ex-unit.hexdocs.pm/ExUnit.Case.html))
- **`ELIXIR-TEST-02`** (MUST) Tests end in `_test.exs` under `test/`, mirroring `lib/`; helpers in `test/support/*.ex` and `test_helper.exs`. Globs `test/**/*_test.exs`, `apps/*/test/**/*_test.exs`. ([Mix.Tasks.Test](https://mix.hexdocs.pm/Mix.Tasks.Test.html))
- **`ELIXIR-TEST-03`** (SHOULD) `describe "fun/arity"` (no nesting), sentence names, one behaviour per test, `setup`, tags for filters, `for` comprehensions for table-style tests. ([ExUnit.Case](https://ex-unit.hexdocs.pm/ExUnit.Case.html))
- **`ELIXIR-TEST-04`** (SHOULD) Prefer fakes and in-memory adapters; Mox against `@behaviour` ports with `verify_on_exit!`, `Mox.allow` for other processes; do not mock what you do not own. ([Mox](https://mox.hexdocs.pm/Mox.html))
- **`ELIXIR-TEST-05`** (MUST) DB tests use the Ecto SQL Sandbox: `pool: Ecto.Adapters.SQL.Sandbox`, `Sandbox.mode(Repo, :manual)` in `test_helper.exs`, `start_owner!(Repo, shared: not tags[:async])`, `allow/3` for other processes. Async only on PostgreSQL. Never mock the DB. ([Sandbox](https://ecto-sql.hexdocs.pm/Ecto.Adapters.SQL.Sandbox.html))
- **`ELIXIR-TEST-06`** (MUST) Coverage config: `test_coverage: [tool: ExCoveralls]` and `cli/0` `preferred_envs` (`coveralls*: :test`) in `mix.exs`; `coveralls.json` with `minimum_coverage: 0` (loops owns the threshold), `skip_files`, `# coveralls-ignore-start/-stop/-next-line`. ([excoveralls](https://github.com/parroty/excoveralls))
- **`ELIXIR-TEST-07`** (MUST) New-code coverage is computed by loops from `cover/lcov.info` (`SF:`, `DA:`) against the diff; `SF:` paths are absolute and normalised to project-relative. Ignore `test/**`, `priv/repo/migrations/**`, generated code. ([diff-cover](https://github.com/Bachmann1234/diff_cover))
- **`ELIXIR-TEST-08`** (SHOULD) Property tests with StreamData (`use ExUnitProperties`, `check all`; seed = ExUnit seed) for parsers, serialisers and invariants, beside example tests. ([ExUnitProperties](https://stream-data.hexdocs.pm/ExUnitProperties.html))
- **`ELIXIR-TEST-09`** (MUST) No flakiness: `async: true`; no global state in async modules (`Application.put_env`, named processes) or mark `async: false`; `start_supervised!/1`, `tmp_dir`, `on_exit/1`, `assert_receive` instead of `Process.sleep`; inject clocks; keep the seed. ([ExUnit.Case](https://ex-unit.hexdocs.pm/ExUnit.Case.html))
- **`ELIXIR-TEST-10`** (SHOULD) Fast loop: `mix test file:LINE`, `--stale`, `--failed`, `--trace` (max-cases 1), `--slowest N`; CI `--partitions N` with `MIX_TEST_PARTITION` and `mix test.coverage` merge. ([Mix.Tasks.Test](https://mix.hexdocs.pm/Mix.Tasks.Test.html))
- **`ELIXIR-TEST-11`** (SHOULD) ExMachina or hand-written fixtures in `test/support/`, one factory per schema; never share fixtures that mutate. ([ExMachina](https://hexdocs.pm/ex_machina/ExMachina.html))

## PERF
- **`ELIXIR-PERF-01`** (SHOULD) Benchmark with Benchee (`time:`, `memory_time:`, `save:`/`load:`), never in `dev` or `iex`. ([Benchee](https://benchee.hexdocs.pm/Benchee.html))
- **`ELIXIR-PERF-02`** (SHOULD) Profile with `mix profile.tprof` (OTP 27+), `eprof` or `fprof`; live: `:observer`, `:recon`, telemetry. ([Profile.Tprof](https://mix.hexdocs.pm/Mix.Tasks.Profile.Tprof.html))
- **`ELIXIR-PERF-03`** (SHOULD) Tune the VM only after measuring: schedulers (`+S`), `:max_heap_size`, ETS `read_concurrency`/`write_concurrency`, `rel/vm.args.eex`. ([Release](https://mix.hexdocs.pm/Mix.Tasks.Release.html))
- **`ELIXIR-PERF-04`** (AVOID) `++` on large lists in loops, `Enum.at`/`length` on lists in loops, `String.to_atom` on input, per-request `Process.sleep`, N+1 Ecto queries, large messages, `Enum` over `Stream` for huge data, global GenServer bottlenecks. ([code anti-patterns](https://elixir.hexdocs.pm/code-anti-patterns.html))

## SEC
- **`ELIXIR-SEC-01`** (MUST) SQL via Ecto `^` interpolation, `fragment("... ?", ^x)` or `Repo.query/3` with params; never interpolate into `fragment/1`. Shell via `System.cmd(cmd, args)`, not `:os.cmd/1`. ([EEF hardening](https://security.erlef.org/secure_coding_and_deployment_hardening/))
- **`ELIXIR-SEC-02`** (MUST) No `binary_to_term/1` on untrusted data (`[:safe]` at least; prefer JSON/Protobuf); no `Code.eval_string`/`eval_quoted` on input; no atom-creating YAML loaders. ([EEF hardening](https://security.erlef.org/secure_coding_and_deployment_hardening/))
- **`ELIXIR-SEC-03`** (MUST) `String.to_existing_atom/1` or an explicit map, never `String.to_atom/1` on external input (atom exhaustion). ([code anti-patterns](https://elixir.hexdocs.pm/code-anti-patterns.html))
- **`ELIXIR-SEC-04`** (MUST) Keep `protect_from_forgery` and `put_secure_browser_headers` in `:browser`; no `raw/1` on user input; `Path.safe_relative/2` before file access; validate redirects; explicit CORS; SSRF-check outbound URLs. ([Phoenix security](https://phoenix.hexdocs.pm/security.html))
- **`ELIXIR-SEC-05`** (MUST) Secrets from the environment in `config/runtime.exs`, never `config.exs`; `mix phx.gen.secret`; hash with `argon2_elixir`/`bcrypt_elixir`/`pbkdf2_elixir`; `Plug.Crypto.secure_compare/2`; tokens from `:crypto.strong_rand_bytes/1`, not `:rand`. ([Phoenix releases](https://phoenix.hexdocs.pm/releases.html))
- **`ELIXIR-SEC-06`** (MUST) Validate at the adapter boundary with changesets (`cast(attrs, [:field])`, schemaless too) or `NimbleOptions`; never pass raw `params` into the domain. ([Ecto.Changeset](https://ecto.hexdocs.pm/Ecto.Changeset.html))
- **`ELIXIR-SEC-07`** (MUST) Commit `mix.lock` (checksums are verified), review `mix deps.update` diffs, no `git:` deps without a pinned `ref:`, enable `HEX_NO_VERIFY_REPO_ORIGIN` only deliberately. ([Hex](https://hex.hexdocs.pm/Mix.Tasks.Hex.html))
- **`ELIXIR-SEC-08`** (SHOULD) `mix sobelow --exit medium` (`--skip` via `# sobelow_skip`, `.sobelow-conf`); Phoenix-focused. ([Sobelow](https://github.com/nccgroup/sobelow))
- **`ELIXIR-SEC-09`** (MUST) Hardening: no exposed EPMD or distribution ports, secret `RELEASE_COOKIE`, TLS `verify_peer` with CA store (`:public_key.cacerts_get/0`), no crash dumps in production. ([EEF hardening](https://security.erlef.org/secure_coding_and_deployment_hardening/))

## DATA
- **`ELIXIR-DATA-01`** (SHOULD) Ecto with `Repo` as the only DB gateway; `Repo.query`/`fragment` for what the DSL cannot express. No identity map or lazy loading: preload explicitly. With hexagonal, keep schemas in adapters and return domain structs. ([Ecto.Repo](https://ecto.hexdocs.pm/Ecto.Repo.html))
- **`ELIXIR-DATA-02`** (MUST) `mix ecto.gen.migration`, timestamped, prefer `change/0`, `up/down` when irreversible (`modify/3` needs `:from`). Deploy by running `MyApp.Release.migrate` through the release script, as the Phoenix release guide shows. ([Ecto.Migration](https://ecto-sql.hexdocs.pm/Ecto.Migration.html))

## Top 10 footguns
1. Process as code organisation (GenServer around pure functions) → plain module.
2. `String.to_atom(params["role"])` → `String.to_existing_atom/1` or an explicit map.
3. `spawn/1` or `Task.start/1` for long-lived work → `Task.Supervisor` or a child spec.
4. Slow `init/1` or unbounded `GenServer.call` → `handle_continue/2` and explicit timeouts.
5. `map[:id]` for a required key → `map.id` or pattern match.
6. `async: true` with `Application.put_env` or a named process → `async: false` or per-test isolation; re-run with `--seed N`.
7. Spawned process without `Sandbox.allow/3`, or async on MySQL → `start_owner!`, `allow`, PostgreSQL.
8. `create index` on a big table inside a transaction → `concurrently: true`, `@disable_ddl_transaction true`, advisory lock.
9. `System.get_env` in `config.exs` → `config/runtime.exs`.
10. `Task.async(fn -> use(conn) end)` sends the whole struct → extract the needed fields first.
