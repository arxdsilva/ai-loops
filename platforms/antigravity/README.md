# loops for Google Antigravity

Tier A (resumable custom subagents). Generated by `loops port build` from the
canonical plugin; do not edit (specs/PLATFORMS.md §3.6).

## Install

Native Antigravity plugin:

    agy plugin validate ./platforms/antigravity
    agy plugin install ./platforms/antigravity

Or install into workspace / user customization directories:

    npx ai-loops --target antigravity
    loops install --target antigravity [--scope project|user]

- Project scope places skills in .agents/skills/, subagents in .agents/agents/,
  rules in .agents/rules/, hooks in .agents/hooks.json, and shared plugin files
  (specs, templates, bin/loops shim) in .loops/plugin/.
- User scope places skills in ~/.gemini/config/skills/, subagents in
  ~/.gemini/config/agents/, rules in ~/.gemini/config/rules/, hooks in
  ~/.gemini/config/hooks.json, and shared plugin files in
  ~/.local/share/loops/plugin/.

## Use

- Commands & skills: `/work`, `/init`, `/status`, `/report` (run `/skills reload`
  after installing or updating).
- Rules: always-on context lives in rules/AGENTS.md.
- Subagents: custom agents in agents/<role>.md (`subagent: true`,
  `mainAgent: false`, `commandExecutionPolicy: "auto"`), spawned via
  `invoke_subagent` and resumed when idle via `send_message` with full context.
  Read-only roles rely on instruction enforcement (`tools` omitted so roles can
  write their run-dir files and avoid tool-validation hangs).
- Hooks: hooks.json registers SessionStart, PreToolUse, PostToolUse, and Stop
  with `./bin/loops hook <name> --platform antigravity` (exit 0 + stdout JSON).
  `loops install` rewrites the hook commands to the plugin-home shim.
- Models: roles use `inherit` unless built with `loops port build --models <file.json>`.
