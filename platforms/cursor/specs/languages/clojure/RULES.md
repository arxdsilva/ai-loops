# Clojure rules

Language: Clojure 1.12.x (stable 1.12.6; no LTS) on a Java LTS (21 or 25), `deps.edn` + tools.build. As of 2026-11.
Source: `research/languages/clojure.md` (verified 2026-11-10; the Verification section overrides earlier text). Pack: `specs/languages/clojure/pack.json`.

Rule format: `CLJ-<SEC>-NN` (MUST|SHOULD|AVOID). Project rules win: follow the repo's own config (`deps.edn` aliases, `.clj-kondo/config.edn`, `.cljfmt.edn`, `tests.edn`, framework conventions) over these defaults and log each override with `loops run override`. Universal rules are not repeated: layering is `specs/ARCHITECTURE.md`, SOLID is `specs/SOLID.md`, the gate and race policy are `specs/WORKFLOW.md §6`.

## REPO: repository and project management

Layout, pins and CI order. Universal repo rules: see specs/REPO_PRACTICES.md (when present). There is no lockfile: exact pins are the contract (`CLJ-REPO-05`).

```text
deps.edn  build.clj  tests.edn  .clj-kondo/config.edn  .cljfmt.edn  .tool-versions
src/my_service/{domain,app,adapters}/  system.clj  core.clj(-main)
test/my_service/            # mirrors src, files end in _test.clj
dev/user.clj                # :dev alias only
resources/                  # config.edn, db/migrations, logback.xml
```

Polylith workspace: `workspace.edn`, `components/<n>/{src,test}/...`, `bases/`, `projects/<n>/deps.edn`, `development/`.

- **`CLJ-REPO-01`** (MUST) Use the standard source layout: `src/<ns-path>/…`, `test/…`, `resources/`, one top-level namespace prefix per service (`my-service.*`); put REPL/dev-only code under a `dev/` path added only by the `:dev` alias. `deps.edn` `:paths` is the only layout contract; keeping dev code off the default path stops it shipping in the uberjar. ([source](https://clojure.org/reference/deps_edn))
- **`CLJ-REPO-02`** (MUST) Name namespaces with dashes and files with underscores (`my-service.http.handler` is `src/my_service/http/handler.clj`); one namespace per file; the ns name must equal the file path. The loader maps `-` to `_`; a mismatch fails at require time or breaks AOT. loops arch must apply this mapping. ([source](https://guide.clojure.style))
- **`CLJ-REPO-03`** (SHOULD) Choose `deps.edn` + tools.build for new services; keep Leiningen (`project.clj`) only for existing projects that depend on its plugins. Never mix both as sources of truth for dependencies in one project. `deps.edn` is the official, data-only, tool-agnostic CLI; Leiningen is mature but plugin-driven. Two manifests drift. ([source](https://clojure.org/guides/deps_and_cli))
- **`CLJ-REPO-04`** (SHOULD) Bootstrap with `neil new app` / `clojure -Tnew create` (deps-new) or a team template; day-one repo must contain `deps.edn`, `build.clj`, `tests.edn`, a passing test, `.clj-kondo/`, `.cljfmt.edn`, CI workflow, README, `.gitignore`. A repo that cannot run lint+format+test+build on day one never grows those gates later. ([source](https://github.com/seancorfield/deps-new))
- **`CLJ-REPO-05`** (MUST) Pin every dependency to an exact version: Maven coordinates as exact `{:mvn/version "x.y.z"}` (never `RELEASE`/`LATEST`/ranges), git deps as full `:git/sha` (plus `:git/tag`), tools via `-T` tool installs with pinned versions. There is no lockfile by default; the pinned `deps.edn` is the lock. `deps.edn` resolves transitive deps at runtime and resolution is not locked; exact top-level pins plus `clojure -Stree` snapshots are what teams use. ([source](https://clojure.org/reference/deps_edn))
- **`CLJ-REPO-06`** (SHOULD) Commit a derived dependency snapshot only if reproducibility matters: `clojure -Stree > deps-tree.txt` in CI as an artifact/diff check, or use `clojure -X:deps mvn-pom` to generate and commit `pom.xml` for scanners. Gives reviewers and scanners a resolved graph without a native lockfile. ([source](https://clojure.org/reference/clojure_cli))
- **`CLJ-REPO-07`** (SHOULD) Automate bumps with Renovate (manager matches `deps.edn` and `bb.edn`) or `antq` in CI (`clojure -Tantq outdated`); review each bump with the tests green. Pins without automation rot; Renovate's deps.edn manager updates Maven coords. ([source](https://docs.renovatebot.com/modules/manager/deps-edn/))
- **`CLJ-REPO-08`** (SHOULD) Remove unused dependencies: run `clojure -Tantq` plus `clj-kondo` `:unused-namespace` and `:unused-referred-var`; check that every `:deps` entry is required somewhere. Transitive JVM jars carry CVEs; unused ones add attack surface. ([source](https://github.com/clj-kondo/clj-kondo/blob/master/doc/linters.md))
- **`CLJ-REPO-09`** (MUST) Ship deployables with tools.build: `build.clj` has `clean`, `copy-dir`, `compile-clj`, `uber` into `target/classes` and `target/<lib>-<version>-standalone.jar`; the main ns declares `(:gen-class)` and `-main`. Run `clojure -T:build uber`. Official recipe; AOT only the main ns transitively; deterministic jar names. ([source](https://clojure.org/guides/tools_build))
- **`CLJ-REPO-10`** (SHOULD) Version with SemVer-like coordinates for libraries; derive the version from git (`b/git-count-revs`) or a tag; publish libraries to Clojars/Maven Central with `deps-deploy`, signed (`:sign-releases? true`). Services are not published; the container image tag is the release. Clojure libs keep compatibility by accretion ("never break"); signing is required for Central. ([source](https://github.com/slipset/deps-deploy))
- **`CLJ-REPO-11`** (MUST) Pin the toolchain: `.tool-versions` (asdf/mise) with `java`, `clojure`, `babashka`, `clj-kondo`; pin the Clojure CLI install version in CI; pin the `org.clojure/clojure` version in `deps.edn`. The CLI, JDK and Clojure all vary independently; none is recorded by `deps.edn` except the Clojure jar. ([source](https://clojure.org/guides/install_clojure))
- **`CLJ-REPO-12`** (MUST) `.gitignore` must include `.cpcache/`, `target/`, `.clj-kondo/.cache`, `.lsp/.cache`, `.nrepl-port`, `.lein-*`, `classes/`, `*.class`, `.calva/output-window/`, `hs_err_pid*.log`; commit `.clj-kondo/config.edn` and `.clj-kondo/<lib>/` imported configs. Caches are machine-local; configs are project rules. The CLI docs say add `.cpcache/` to `.gitignore`. ([source](https://clojure.org/reference/clojure_cli))
- **`CLJ-REPO-13`** (SHOULD) CI stages in order: setup JDK+Clojure → `clojure -P -M:test` (prefetch, cached on `deps.edn` hash) → `cljfmt check` → `clj-kondo --lint` → tests with coverage → vulnerability scan → `clojure -T:build uber` → container build. Cache `~/.m2`, `~/.gitlibs`, `.cpcache`. Cheap checks first; deps resolution dominates cold CI time. ([source](https://clojure.org/reference/clojure_cli))
- **`CLJ-REPO-14`** (SHOULD) Use Conventional Commits; they drive changelog and release level; keep one `CHANGELOG.md` (Keep a Changelog). Neutral; nothing Clojure-specific. ([source](https://www.conventionalcommits.org/))
- **`CLJ-REPO-15`** (SHOULD) For several deployables sharing code, use Polylith (`poly` CLI): `components/` (interface + implementation), `bases/` (entry points: HTTP/CLI), `projects/` (deployable assemblies with their own `deps.edn`), `development/` (REPL project). Run `poly check` and `poly test` in CI. Polylith is the de-facto Clojure monorepo architecture and enforces the component interface rule; it is not a build tool, so keep tools.build for artifacts. ([source](https://cljdoc.org/d/polylith/clj-poly/CURRENT/doc/readme))
- **`CLJ-REPO-16`** (SHOULD) Without Polylith, use `deps.edn` `:local/root` deps between sibling directories, or one repo with several `:paths`; never copy namespaces between services. `:local/root` is the native multi-module mechanism (no reactor). ([source](https://clojure.org/reference/deps_edn))
- **`CLJ-REPO-17`** (SHOULD) Prefer a monorepo + Polylith for one team with shared domain code; split repos only when release cadences or ownership differ. Cross-service refactoring is atomic in a monorepo; Polylith gives incremental test/build by changed bricks. ([source](https://cljdoc.org/d/polylith/clj-poly/CURRENT/doc/readme))

## TOOL: toolchain

Gate commands come from `specs/languages/clojure/pack.json`; run them through `loops gate`. `deps.edn` is the base; Leiningen is the `lein` variant.

- **`CLJ-TOOL-01`** (MUST) Target Clojure `1.12.x` (stable 1.12.6, 2026-09-02) on a Java LTS (21 or 25). Do not run production on `1.13.0-alpha*`. Clojure has no LTS; point releases are bug fixes only. 1.12 brought method values, qualified method syntax, array class symbols, `Supplier`/functional-interface conversion; 1.13 alphas are unstable (new ASM, Java 17 bytecode). ([source](https://clojure.org/releases/downloads))
- **`CLJ-TOOL-02`** (MUST) Format with cljfmt (`.cljfmt.edn`): check `clojure -Tcljfmt check` (or `cljfmt check`), fix `cljfmt fix`; run the same argv locally and in CI. zprint is the alternative only if the team picks it as the single formatter. Style-guide formatting is machine-enforced; two formatters fight each other. ([source](https://github.com/weavejester/cljfmt))
- **`CLJ-TOOL-03`** (MUST) Lint with clj-kondo: `clj-kondo --lint src test --parallel`; exit 0 clean, 2 warnings, 3 errors (default `--fail-level warning`); the pack maps 2 and 3 to fail. Commit `.clj-kondo/config.edn`; run `--lint "$(clojure -Spath)" --dependencies --parallel --copy-configs` once to import library hooks and warm the cache. Fast, no compile; library configs (`--copy-configs`) teach it macros like `defroutes` and `deftest`. ([source](https://github.com/clj-kondo/clj-kondo#readme))
- **`CLJ-TOOL-04`** (SHOULD) Treat these clj-kondo findings as errors in CI: `:unresolved-symbol`, `:unresolved-namespace`, `:unused-binding`, `:unused-namespace`, `:redefined-var`, `:inline-def`, `:invalid-arity`, `:type-mismatch`, `:missing-test-assertion`, `:discouraged-var` (for impure fns in the domain). Set via `:linters {:xxx {:level :error}}`. Level lifting makes lint a hard gate without exit-code parsing. ([source](https://github.com/clj-kondo/clj-kondo/blob/master/doc/linters.md))
- **`CLJ-TOOL-05`** (SHOULD) Optionally run Eastwood (`clojure -M:eastwood`) on CI nightly or pre-release; it loads (evaluates) namespaces, so run it only in an environment where loading code is safe. Catches arity/reflection/deprecation/wrong-tag issues clj-kondo can miss, at a cost: slow, evals code. ([source](https://github.com/jonase/eastwood))
- **`CLJ-TOOL-06`** (SHOULD) Clojure is dynamically typed: the "type checker" is clj-kondo (arity, `:type-mismatch`), plus `clojure.spec`/malli at boundaries and `:pre`/`:post` or `assert` for invariants. Instrument with `malli.dev` / `clojure.spec.test.alpha/instrument` in dev and tests only. No compile-time types; instrumentation is dev-time only and costs runtime. ([source](https://clojure.org/guides/spec))
- **`CLJ-TOOL-07`** (MUST) Scan dependencies with nvd-clojure (`nvd` check, `default: off`, needs `NVD_API_TOKEN`; runs `-Tnvd nvd.task/check :classpath ...`) or `clj-watson`; generate `pom.xml` (`clojure -X:deps mvn-pom`) and feed it to OSV-Scanner/Trivy/Dependency-Track as a second opinion. OSV-Scanner does not read `deps.edn`. The check is opt-in locally (`loops gate --vuln`) and required in a CI profile. Native scanners expect lockfiles or `pom.xml`; Clojure's manifest is Clojure code. ([source](https://github.com/rm-hull/nvd-clojure))
- **`CLJ-TOOL-08`** (SHOULD) Generate an SBOM from the resolved classpath: `clojure -X:deps mvn-pom` then CycloneDX Maven plugin or `syft` against the uberjar; record licenses and fail on GPL/AGPL deps unless approved. Supply-chain evidence and license policy; no first-party Clojure SBOM tool. ([source](https://clojure.org/reference/clojure_cli))
- **`CLJ-TOOL-09`** (SHOULD) Editor: clojure-lsp (powered by clj-kondo analysis) + nREPL/Calva/CIDER/Cursive; set format-on-save to cljfmt via clojure-lsp (`:cljfmt` config) so editor and CI agree; commit `.lsp/config.edn`, ignore `.lsp/.cache`. Two formatters (LSP built-in vs CLI) with different configs are the classic format-war. ([source](https://clojure-lsp.io/))

## ARCH: architecture

Layering and the loops hexagon: see specs/ARCHITECTURE.md and specs/SOLID.md. The gate scans `ns` forms with a regex (`arch.parser = regex`, resolver `dotted-module-underscore`) and delegates to `poly check` in Polylith workspaces.

- **`CLJ-ARCH-01`** (MUST) Apply the dependency rule by namespace: `domain` requires nothing outside `domain` and `clojure.*`; `app` requires `domain` (and port protocols); `adapters.*` require `app`/`domain`; only `system`/`core` require adapters. [ARCH-01, ARCH-02]. Same rule as hexagonal; Clojure only has namespaces, so directories are the layers. ([source](https://cljdoc.org/d/polylith/clj-poly/CURRENT/doc/readme))
- **`CLJ-ARCH-02`** (MUST) Parse `(ns … (:require [a.b.c :as x] [d.e :refer [f]]) (:import …))` and `(require '[…])` forms to build the import graph; resolve `a.b.c` to `src/a/b/c.clj(c)` with `-` to `_`. Prefer clj-kondo analysis output (`--config '{:output {:analysis true :format :edn}}'`) over regex. Namespaces are the only module unit; the ns form is the import list; `:as-alias` and prefix lists (`[a.b [c] [d]]`) must be handled. ([source](https://github.com/clj-kondo/clj-kondo/blob/master/analysis/README.md))
- **`CLJ-ARCH-03`** (SHOULD) Enforce boundaries mechanically: (a) clj-kondo `:discouraged-namespace` + `:config-in-ns` per layer (e.g. `my-service.domain.*` forbids `clojure.java.io`, `next.jdbc`, `ring.*`); (b) Polylith `poly check` for interface-only access between components; (c) loops `arch`. There is no ArchUnit; clj-kondo config-in-ns is the cheapest static boundary tool. ([source](https://github.com/clj-kondo/clj-kondo/blob/master/doc/config.md))
- **`CLJ-ARCH-04`** (MUST) Wire manually in `system.clj` with a lifecycle library: Integrant (system as data, `init-key`/`halt-key!`, `#ig/ref`) is the default recommendation; Component for teams already on it (records, explicit `Lifecycle`); Mount only for small apps (global state through var side effects). No service locator and no global atoms of dependencies. Integrant allows anything to depend on anything and the config is edn; Component restricts deps to records/maps; Mount's implicit globals hamper tests and the REPL reset. ([source](https://github.com/weavejester/integrant))
- **`CLJ-ARCH-05`** (MUST) Pass ports and dependencies as an explicit first argument (a map `{:keys [repo clock]}`) to use-case functions; never `(def conn ...)` at namespace level or `(atom ...)` globals holding collaborators. Plain functions with a deps map are trivially testable with fakes; `def`'d state breaks REPL reload and parallel tests. ([source](https://github.com/stuartsierra/component))
- **`CLJ-ARCH-06`** (MUST) Keep the domain pure: no `System/currentTimeMillis`, `Instant/now`, `rand`, `random-uuid`, `slurp`, `spit`, `future`, `swap!` on shared atoms, or `java.io`/`java.sql`/`java.net`/`ring`/`next.jdbc` requires; pass time and ids in as data or via a port. Immutable data and pure functions are Clojure's core property; one `Instant/now` in the domain makes tests time-dependent. ([source](https://clojure.org/about/rationale))
- **`CLJ-ARCH-07`** (SHOULD) Use protocols for polymorphism on the type of the first argument, defined by the consumer (`app/ports.clj`) and kept to 1-5 methods; use multimethods only for open dispatch on data (e.g. event type, `:type` keyword); use a plain map of functions for simple strategy seams. Protocols compile to fast interface dispatch; multimethods are slower but dispatch on arbitrary values and are open. ([source](https://clojure.org/reference/protocols))
- **`CLJ-ARCH-08`** (SHOULD) Model data with maps and validate at boundaries with malli or clojure.spec; do not wrap every entity in `defrecord` unless you need protocol dispatch or performance. Keep one schema namespace per bounded context. Maps compose and serialize for free; records add type-based dispatch and interop but lose some map ergonomics. ([source](https://github.com/metosin/malli))
- **`CLJ-ARCH-09`** (SHOULD) SOLID sizes: function under ~15 lines, namespace under ~400 lines, at most 4 positional params (use a map beyond that), no more than ~8 public vars per port protocol, no circular requires (the compiler rejects cycles). Clojure style: small composable fns; cycles are a compile error, so cycles reveal hidden layering mistakes. ([source](https://guide.clojure.style))
- **`CLJ-ARCH-10`** (SHOULD) Prefer a modular monolith (Polylith components in one project) first; split into projects (deployables) only on a scaling, ownership or release-cadence need. Use CQRS/event sourcing only where audit or temporal queries are a requirement. Polylith lets the same components be assembled into one or many deployables without rewriting. ([source](https://cljdoc.org/d/polylith/clj-poly/CURRENT/doc/readme))

## IDIOM: what to do and what to avoid

- **`CLJ-IDIOM-01`** (MUST) Return data for expected failures (`{:error/type :not-found ...}` or anomaly maps) and throw `ex-info` with a data map (`:type`, cause) for exceptional ones; catch at the adapter boundary and map to HTTP status; never swallow with an empty `catch` or a bare `(catch Exception _ nil)`. Clojure has no checked exceptions or Result type; `ex-info` carries structured data and `ex-data` reads it. ([source](https://guide.clojure.style))
- **`CLJ-IDIOM-02`** (MUST) Wrap causes: `(throw (ex-info "msg" {:order-id id} cause))`; log once at the outermost boundary; use `try`/`catch` with the most specific class; use `finally` only for cleanup. Preserves the stack and data without double logging. ([source](https://clojuredocs.org/clojure.core/ex-data))
- **`CLJ-IDIOM-03`** (MUST) `nil` is falsey, `()`/`[]`/`{}`/`""` are truthy, and `(seq coll)` is the emptiness idiom (not `(not (empty? ...))`); use `some?`/`nil?` when `false` is a legal value; use `(some-> ...)`/`(when-let ...)`/`(if-some ...)` to thread nil safely. `nil` punning is idiomatic but `false` vs `nil` bugs are the top trap (`(or false 1)`, `(get {:a false} :a :default)`). ([source](https://guide.clojure.style))
- **`CLJ-IDIOM-04`** (MUST) Use immutable persistent collections everywhere; use `assoc`/`update`/`assoc-in`/`update-in`; use transients (`transient`, `persistent!`) only locally inside a function for measured hot loops; never mutate Java collections that cross a function boundary. Persistent structures give structural sharing; transients are single-thread, local-only. ([source](https://clojure.org/reference/transients))
- **`CLJ-IDIOM-05`** (SHOULD) Use `defrecord` for domain entities only when protocol dispatch is needed; otherwise maps with namespaced keywords (`:order/id`); use `clojure.spec`/malli to describe shapes; prefer qualified keywords for inter-ns data. Qualified keys avoid collisions when maps merge across contexts. ([source](https://clojure.org/guides/spec))
- **`CLJ-IDIOM-06`** (SHOULD) Prefer spec **or** malli, not both: malli (schemas as data, coercion/transformers, Reitit integration, OpenAPI generation) for new HTTP services; clojure.spec when targeting library-level contracts without extra deps. Do not call spec `s/valid?` on hot paths in production. Both validate data; malli is data-first and ties to Reitit/coercion; spec macros need compile-time registration and have no built-in coercion. Unsettled; see Open questions. ([source](https://github.com/metosin/malli))
- **`CLJ-IDIOM-07`** (MUST) Release resources with `with-open` (any `java.io.Closeable`), or a lifecycle `halt-key!`; never leave `ResultSet`, `Connection`, streams or `ExecutorService` unclosed; realize lazy seqs inside the `with-open` scope (`doall`, `into`, `reduce`). Lazy sequences escaping `with-open` read a closed resource. ([source](https://clojure.org/reference/java_interop))
- **`CLJ-IDIOM-08`** (MUST) Never let laziness escape resource, dynamic-binding or transaction scope; avoid `lazy-seq` over I/O; use `reduce`/`transduce`/`run!`/`doseq` for side effects, never `map`/`for` for side effects. `(map println xs)` does nothing until realised and may run twice or in chunks of 32. ([source](https://clojure.org/reference/lazy))
- **`CLJ-IDIOM-09`** (MUST) Equality is value-based (`=`); `==` is numeric only; `identical?` only for reference identity; mind that `(= 1 1N)` and `(= 1 1.0)` differ across number categories; keys in maps are compared with `=`/`hash` consistency; never use mutable objects as keys. Mixed-numeric keys silently miss in maps. ([source](https://clojure.org/guides/equality))
- **`CLJ-IDIOM-10`** (MUST) Use `java.time` through `clojure.java-time` or direct interop; always carry an explicit zone (`ZoneOffset/UTC`, `Instant`); never use `java.util.Date`/`SimpleDateFormat`; use `BigDecimal`/`bigdec` for money; arithmetic with `+`/`*` throws on long overflow, `+'` auto-promotes. Long overflow raises `ArithmeticException`; Doubles lose cents. ([source](https://clojure.org/reference/data_structures#Numbers))
- **`CLJ-IDIOM-11`** (SHOULD) Naming: `kebab-case` for vars, namespaces and keywords; predicates end in `?`; unsafe/side-effecting end in `!`; conversions `x->y`; private helpers `defn-`; docstrings on public vars, placed before the arg vector. Community style, checked by clj-kondo/cljfmt where possible. ([source](https://guide.clojure.style))
- **`CLJ-IDIOM-12`** (MUST) Use macros only when a function cannot do the job (control-flow/binding forms, DSLs); write the function first and a thin macro over it; never use runtime code evaluation or `read-string` on untrusted input, or `load-string` in production paths. Macros are not first-class and defeat tooling; runtime evaluation and `read-string` are code-execution vectors. ([source](https://clojure.org/reference/macros))
- **`CLJ-IDIOM-13`** (SHOULD) Avoid reflection: put `(set! *warn-on-reflection* true)` at the top of every namespace (or in a CI task) and eliminate every warning with a type hint (`^String s`, return hints before the arg vector). Add hints only where a warning appears. Reflective interop is 10-100x slower and fails at runtime if hints are wrong; the default is `false`. ([source](https://clojure.org/reference/java_interop))
- **`CLJ-IDIOM-14`** (SHOULD) Prefer function composition and `->`, `->>`, `as->`, `cond->`; avoid deep nesting; use destructuring (`{:keys [a b] :or {...}}`) in params; avoid `declare` forward references unless needed; no `def` inside functions (`:inline-def`). Idiomatic readability; `def` inside fns mutates the namespace at runtime. ([source](https://guide.clojure.style))

## CONC: concurrency and the `-race` equivalent

**Race policy: `mode = none`.** The JVM has no data-race detector; the substitute is the required `test-repeat` check (`CLJ-CONC-08`, WORKFLOW §6).

- **`CLJ-CONC-01`** (MUST) Hold shared state in exactly one managed reference: `atom` for independent state, `ref` + `dosync` for coordinated multi-ref transactions, `agent` for asynchronous single-writer state; use `swap!` with a pure function; do side effects only outside transaction/`swap!` functions (they may retry). `swap!` retries in a spin loop; STM retries a transaction. A side effect inside runs multiple times. ([source](https://clojure.org/reference/atoms))
- **`CLJ-CONC-02`** (SHOULD) Prefer one `atom` holding one immutable map over several atoms; use `swap-vals!`/`compare-and-set!` when you need the old value; use `io!` in functions that must not run inside `dosync`; avoid `ref` unless you truly need cross-ref consistency. Fewer references means fewer ordering hazards; STM is rarely needed. ([source](https://clojure.org/reference/atoms))
- **`CLJ-CONC-03`** (MUST) Use `delay`/`promise`/`future` deliberately: `deref` with a timeout `(deref f 5000 :timeout)`; a `future` swallows exceptions until deref; never `deref` in a tight loop; call `shutdown-agents` on exit or the JVM may hang 60 s. Futures and agents use non-daemon pools; unhandled exceptions vanish silently. ([source](https://clojure.org/reference/refs#_future))
- **`CLJ-CONC-04`** (MUST) In core.async: never block (`<!!`, `Thread/sleep`, JDBC, HTTP) inside a `go` block; use `thread` or `a/io-thread` for blocking work; use bounded buffers (`(chan 100)`, `sliding-buffer`, `dropping-buffer`) for backpressure; close channels you own; always include a timeout (`alts!` + `timeout`) when waiting on external input. `go` blocks share a small fixed pool (8 threads); one blocking call can starve all. Unbounded channels are not allowed (max 1024 pending puts). ([source](https://github.com/clojure/core.async))
- **`CLJ-CONC-05`** (MUST) Catch exceptions inside every `go` block and every `future`/agent action (`set-error-handler!`, `:error-mode :continue`); an uncaught exception in a `go` block is lost to the default uncaught-exception handler. Lost errors turn into hung pipelines. ([source](https://github.com/clojure/core.async))
- **`CLJ-CONC-06`** (MUST) Run background work on explicit `ExecutorService`s created in the lifecycle (Integrant `init-key`) and shut down in `halt-key!` with `.shutdown` + `.awaitTermination`; name threads; stop consuming new work first, then drain. Graceful shutdown needs an owner; unowned pools leak across REPL resets. ([source](https://github.com/weavejester/integrant))
- **`CLJ-CONC-07`** (AVOID) Avoid `def`/`alter-var-root`/`set!` for state, and avoid dynamic vars (`binding`) crossing threads: binding conveyance applies to `future`/`pmap`/`agent` sends but not to raw `Thread` or core.async `go` blocks reliably. Thread-local bindings are a hidden-parameter race source. ([source](https://clojure.org/reference/vars))
- **`CLJ-CONC-08`** (SHOULD) Race substitute (`race.mode = none`): the required `test-repeat` check runs Kaocha with `--randomize --seed {seed}` three times (a new printed seed each run) and fails on the first failure; never use `--no-randomize` or retries in the gate. Review items: tests tagged `^:concurrency` repeated 20 times (`--focus-meta :concurrency`) and reflection warnings clean. Without a detector, repetition and shuffling are the only machine checks. ([source](https://github.com/lambdaisland/kaocha))

## TEST: testing

Coverage is lcov at `{coverage_dir}/lcov.info` from cloverage (`CLJ-TEST-06`); wave 0 adds the `:test` and `:cov` aliases and `tests.edn` (D13).

- **`CLJ-TEST-01`** (MUST) Use `clojure.test` (`deftest`, `is`, `testing`, `are`) run by Kaocha (`clojure -M:test`); use `matcher-combinators` for structural assertions; use `lambdaisland/kaocha` over `lein test` for focus, watch, plugins and reporters. Kaocha is the de-facto runner with a config file (`tests.edn`) and plugins. ([source](https://github.com/lambdaisland/kaocha))
- **`CLJ-TEST-02`** (MUST) Tests live under `test/` mirroring `src/`; the namespace ends in `-test` (file `*_test.clj`/`*_test.cljc`); Kaocha `:ns-patterns ["-test$"]`; unit and integration split into two Kaocha suites (`:unit`, `:integration`) selectable by `--focus`/`--skip-meta`. Test-file globs: `test/**/*_test.clj`, `test/**/*_test.cljc`. The loops test guard and coverage exclusion need the glob. ([source](https://github.com/lambdaisland/kaocha))
- **`CLJ-TEST-03`** (SHOULD) Use `are` for table-style cases and `testing` strings that read as a sentence; one logical assertion per `testing`; arrange data as plain maps built by small factory fns in a `test/<ns>/fixtures.clj`; use `use-fixtures :each` for state reset. `are` is clojure.test's table form; fixtures isolate state. ([source](https://clojure.github.io/clojure/clojure.test-api.html))
- **`CLJ-TEST-04`** (SHOULD) Test with fakes (a record or `reify` implementing the port protocol, or `{:find-order (fn ...)}` maps), not mocking libraries; use `with-redefs` only in rare unit tests and never in parallel tests; use `mockery`/`clj-fakes` only for third-party seams. `with-redefs` mutates global vars (thread-unsafe); fakes keep tests deterministic and let the domain be tested pure. ([source](https://clojure.github.io/clojure/clojure.core-api.html#clojure.core/with-redefs))
- **`CLJ-TEST-05`** (SHOULD) Integration tests use real Postgres via Testcontainers (`clj-test-containers`) or an embedded DB started in a Kaocha/Integrant fixture; isolate each test in a transaction rolled back, or a fresh schema; reset the system with Integrant `halt!`/`init`. Mocked SQL hides dialect and migration errors; a data-as-system makes per-test restarts cheap. ([source](https://github.com/javahippie/clj-test-containers))
- **`CLJ-TEST-06`** (MUST) Measure coverage with cloverage through the `:cov` alias: the gate runs `clojure -M:cov -o {coverage_dir}` and reads `{coverage_dir}/lcov.info` (lcov, relative `SF:src/...` paths, `DA:` line records; the alias carries `--lcov --no-html -p src -s test`, a D13 prerequisite). Exclude generated namespaces with `--ns-exclude-regex`. Cloverage reports form/line coverage only and runs `clojure.test`, not Kaocha (kaocha-cloverage has no output flag). Only cloverage targets Clojure forms; JaCoCo works on bytecode but is noisy with Clojure's generated classes. ([source](https://github.com/cloverage/cloverage))
- **`CLJ-TEST-07`** (MUST) New-code coverage (>= 70%) is computed by loops: it parses `lcov.info` (`SF:`, `DA:line,hits`) and intersects it with the added lines of `git diff --unified=0 <base>`; `diff-cover` is not needed. `.clj` and `.cljc` are candidates; `*_test.clj` files are excluded. Cloverage does not know about the diff; the diff logic is neutral and lives in loops. ([source](https://github.com/Bachmann1234/diff_cover))
- **`CLJ-TEST-08`** (SHOULD) Add `test.check` property tests (`clojure.test.check.clojure-test/defspec`, `prop/for-all`) for parsers, pure domain rules and idempotency; use `malli.generator`/`s/gen` to derive generators from schemas; run ≥100 iterations in CI. Property tests find edge cases tables miss. ([source](https://github.com/clojure/test.check))
- **`CLJ-TEST-09`** (SHOULD) Mutation testing is optional (no mainstream Clojure mutation tool was identified; Jepsen is for distributed-system fault testing); do not gate on it. No established tooling found; unsettled. ([source](https://github.com/jepsen-io/jepsen))
- **`CLJ-TEST-10`** (MUST) Keep tests deterministic: inject clock/rand/uuid via ports; seed `test.check` (`:seed`) when reproducing; Kaocha randomises order and prints the seed (`--seed N`, `--no-randomize` to debug); add timeouts to futures/promises in tests; never share atoms across tests. Order dependence and clock reads are the main flake sources. ([source](https://github.com/lambdaisland/kaocha))
- **`CLJ-TEST-11`** (SHOULD) Fast TDD loop in the REPL: `(clojure.test/run-tests 'my.ns-test)`, Kaocha `--focus my.ns-test/my-test`, `--watch`, `--fail-fast`; use `clojure.tools.namespace.repl/refresh` or Integrant `reset` to reload; keep a `user.clj` with `(go)` / `(reset)`. Sub-second feedback needs a running REPL; cold JVM start is the cost to avoid. ([source](https://clojure.org/guides/repl/introduction))

## PERF: performance and profiling

- **`CLJ-PERF-01`** (SHOULD) Benchmark with criterium (`quick-bench`, `bench`) in the REPL or JMH via `jmh-clojure`/`criterium` in a `:bench` alias; compare runs statistically, never with `time`. `time` includes JIT warm-up and GC noise. ([source](https://github.com/hugoduncan/criterium))
- **`CLJ-PERF-02`** (SHOULD) Profile with clj-async-profiler (flamegraphs, CPU/alloc) or JFR (`-XX:+FlightRecorder` / `jcmd <pid> JFR.start`), view in JMC/VisualVM; use continuous profiling (Pyroscope/async-profiler agent) in prod. JVM profilers see through Clojure fn names (`ns$fn`). ([source](https://github.com/clojure-goes-fast/clj-async-profiler))
- **`CLJ-PERF-03`** (SHOULD) Tune the JVM, not Clojure: set `-Xmx`/`-XX:MaxRAMPercentage=75` for containers, pick G1 (default) or ZGC, use `-XX:+UseContainerSupport` (default), enable direct linking for AOT builds (`-Dclojure.compiler.direct-linking=true`) at the cost of REPL redefinition. Container-aware heap sizing and direct linking speed fn calls but break `with-redefs`. ([source](https://clojure.org/reference/compilation))
- **`CLJ-PERF-04`** (AVOID) Avoid: reflection (type-hint), boxed math in hot loops (`^long`/`^double` hints, `unchecked-*` only after profiling), `apply str` in loops (use `StringBuilder`/`str` with `reduce`), `(count lazy-seq)`, `concat` chains, `into []` from huge lazy seqs without transducers, `keys`/`vals` recomputed per iteration, `memoize` on unbounded keys. These are the standard Clojure hot-path traps. ([source](https://clojure.org/reference/java_interop))
- **`CLJ-PERF-05`** (SHOULD) Use transducers (`(into [] (comp (map f) (filter p)) xs)`) and `reduce` for pipelines on large collections instead of chained lazy `map`/`filter`; use `pmap` only for CPU-heavy pure functions with coarse chunks. No intermediate lazy seqs; `pmap` overhead dominates on small work. ([source](https://clojure.org/reference/transducers))

## SEC: security

- **`CLJ-SEC-01`** (MUST) Build SQL with HoneySQL maps and `?` params (`(sql/format {:select [:*] :from [:users] :where [:= :id id]})`) executed by next.jdbc; never concatenate user input into SQL strings; whitelist dynamic identifiers/column names; never use `:raw`/`[:raw ...]` with user input. Parameter binding is the only safe path; HoneySQL's `:raw` re-opens injection. ([source](https://cheatsheetseries.owasp.org/cheatsheets/SQL_Injection_Prevention_Cheat_Sheet.html))
- **`CLJ-SEC-02`** (MUST) Shell out with `clojure.java.shell/sh` or `ProcessBuilder` with an argument vector, never through `sh -c` and a concatenated string; validate against an allow-list. Argument vectors avoid shell interpretation. ([source](https://cheatsheetseries.owasp.org/cheatsheets/OS_Command_Injection_Defense_Cheat_Sheet.html))
- **`CLJ-SEC-03`** (MUST) Parse untrusted data with `clojure.edn/read-string` (with `:readers` restricted) or JSON (jsonista/cheshire); NEVER `clojure.core/read-string`, `load-string` or runtime code evaluation on input, and never turn on read-time evaluation (the reader's evaluation flag); avoid Java `ObjectInputStream`; keep YAML parsers in safe mode. `read-string` with `#=` executes code; Java serialization gadget chains are a known RCE class. ([source](https://cheatsheetseries.owasp.org/cheatsheets/Deserialization_Cheat_Sheet.html))
- **`CLJ-SEC-04`** (MUST) Use `ring-defaults` (`secure-site-defaults`/`secure-api-defaults`) for security headers, CSRF (`ring.middleware.anti-forgery`), HTTPS redirect, and same-site cookies; use `ring-cors` with an explicit origin allow-list, never `*` with credentials. `site-defaults` add CSRF and cookie protection; APIs must opt in per route. ([source](https://github.com/ring-clojure/ring-defaults))
- **`CLJ-SEC-05`** (MUST) Defend SSRF and traversal: allow-list outbound hosts, resolve and block internal IPs before `hato`/`clj-http` calls; serve files with `ring.util.response/file-response` with a `:root` and reject `..`; use `ring.middleware.resource` rather than hand-built paths. Ring's file helpers confine paths when given a root. ([source](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html))
- **`CLJ-SEC-06`** (MUST) Read secrets from env vars or a vault (aero `#env`, Integrant config, Vault); never commit them to `config.edn` or print config maps/errors that contain them; redact with a `:secret` key convention in logging. Config maps with passwords are routinely logged by REPL helpers and `ex-data`. ([source](https://cheatsheetseries.owasp.org/cheatsheets/Secrets_Management_Cheat_Sheet.html))
- **`CLJ-SEC-07`** (MUST) Hash passwords with `buddy-hashers` using argon2id or bcrypt; use JCA via `buddy-core` for crypto; use `java.security.SecureRandom` (never `rand`/`rand-int`) for tokens; JWT via `buddy-sign` with algorithm pinned. `rand` is not cryptographically secure. ([source](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html))
- **`CLJ-SEC-08`** (MUST) Validate and coerce all input at the HTTP adapter with malli/spec coercion (Reitit `:coercion`), return 400/422 with problem details; do not validate deep in the domain. Validation at the boundary keeps the domain trusted. ([source](https://cljdoc.org/d/metosin/reitit/CURRENT/doc/coercion/coercion))
- **`CLJ-SEC-09`** (MUST) Supply chain: pin versions/SHAs (REPO-05); prefer Clojars/Central artifacts from known groups; verify git deps by `:git/sha`, not a branch; run the dependency scan on every PR; do not set `CLOJURE_CLI_ALLOW_HTTP_REPO`. There is no lockfile hash check; an `http://` repo allows MITM. ([source](https://clojure.org/reference/clojure_cli))
- **`CLJ-SEC-10`** (SHOULD) Run SAST with `clj-kondo` security hooks plus Semgrep (Clojure supported) and, for interop-heavy code, SpotBugs + FindSecBugs on the uberjar; `clj-holmes` (rules over source) is available. No bandit/brakeman equivalent exists; Semgrep and clj-holmes fill the gap. ([source](https://semgrep.dev/docs/supported-languages))

## DATA: persistence

- **`CLJ-DATA-01`** (SHOULD) Use next.jdbc (`execute!`, `execute-one!`, `plan`) with HoneySQL for queries; no full ORM; map rows to domain maps in the outbound adapter; use the default table-qualified keys; pass `:builder-fn rs/as-unqualified-kebab-maps` only if you set it once through `jdbc/with-options`. SQL as data composes; ORMs fight immutable data. ([source](https://github.com/seancorfield/next-jdbc/blob/develop/doc/getting-started.md))
- **`CLJ-DATA-02`** (MUST) Use Migratus or Ragtime with versioned `.sql` files (`resources/migrations/20261110-add-orders.up.sql`) run at startup by a separate job/command, not by every replica; forward-only in production, expand-then-contract for zero-downtime. Migration tools differ in reversible support; multi-replica startup migrations race. ([source](https://github.com/yogthos/migratus))
- **`CLJ-DATA-03`** (MUST) Open transactions in the application layer with `jdbc/with-transaction [tx ds]` (commit on success, rollback on exception) and pass `tx` to repository functions; never start transactions in HTTP handlers or domain. Transaction boundary = use case boundary. ([source](https://github.com/seancorfield/next-jdbc/blob/develop/doc/transactions.md))
- **`CLJ-DATA-04`** (MUST) N+1: next.jdbc has no lazy loading, but repeated queries in `map` are the Clojure N+1; batch with `WHERE id IN (...)` (HoneySQL `[:in :id ids]`) and group in memory; use `jdbc/plan` + `reduce` to stream large results inside the connection scope. `plan` is a reducible; consuming outside the connection reads a closed ResultSet. ([source](https://github.com/seancorfield/next-jdbc/blob/develop/doc/getting-started.md))
- **`CLJ-DATA-05`** (MUST) Pool with HikariCP via `next.jdbc.connection/->pool` (`:username` not `:user`); set `:maximumPoolSize`, `:connectionTimeout`, `:maxLifetime`; call `get-connection` at startup to fail fast; close the pool in `halt-key!`. Pool validation is deferred; unbounded pools exhaust the DB. ([source](https://github.com/seancorfield/next-jdbc/blob/develop/doc/getting-started.md))

## API: APIs and integration

- **`CLJ-API-01`** (SHOULD) Build HTTP on Ring (handler = fn of request map to response map, middleware = fn wrapping a handler) with Reitit as router (data-driven routes, per-route middleware/interceptors, coercion); use Jetty or http-kit adapters; Pedestal when you want interceptors and a full service framework. Ring is the standard abstraction; Reitit is the dominant router. ([source](https://github.com/ring-clojure/ring/wiki))
- **`CLJ-API-02`** (SHOULD) Describe the API as data in Reitit routes and generate OpenAPI via `reitit-swagger`; for contract-first teams validate responses against the OpenAPI file in tests; use malli for request/response schemas. One source of truth for validation and docs. ([source](https://cljdoc.org/d/metosin/reitit/CURRENT/doc/ring/swagger))
- **`CLJ-API-03`** (MUST) Return RFC 9457 problem details (`application/problem+json`) from an exception-handling middleware (`reitit.ring.middleware.exception`) mapping `ex-data` `:type` to status codes; never leak stack traces. Uniform errors; the middleware turns `ex-info` into responses. ([source](https://www.rfc-editor.org/rfc/rfc9457))
- **`CLJ-API-04`** (MUST) Set timeouts on every outbound call (connect + read), retry only idempotent requests with exponential backoff and jitter (`diehard`/`again`), add circuit breakers (`diehard`), rate-limit at the edge, and require `Idempotency-Key` for POST. Clients without timeouts hang threads. ([source](https://github.com/sunng87/diehard))
- **`CLJ-API-05`** (SHOULD) Use `hato` (java.net.http) or `clj-http` with a shared client, explicit timeouts, and connection reuse; do not create a client per request; propagate deadlines and correlation IDs as headers. A client per call defeats keep-alive. ([source](https://github.com/gnarroway/hato))
- **`CLJ-API-06`** (MUST) Messaging: use the Java clients via interop wrappers (`jackdaw` for Kafka, `langohr`, `amazonica`/Cognitect aws-api for SQS, `nats.clj`); implement the outbox pattern in the same DB transaction; make consumers idempotent; commit offsets after processing. At-least-once delivery means duplicates. ([source](https://github.com/FundingCircle/jackdaw))

## FW: frameworks

Framework conventions win over loops layering when they conflict; log the override (`CLJ-FW-02`).

- **`CLJ-FW-01`** (SHOULD) Choose from the dominant stack: Ring (+ Jetty/http-kit) with Reitit (library-style, data-driven), Pedestal (interceptor-based service framework), or Compojure/Ring for older code. No authoritative usage figures were found; ranking is by ecosystem prominence (see Open questions). Clojure favours libraries over frameworks. ([source](https://github.com/ring-clojure/ring))
- **`CLJ-FW-02`** (SHOULD) Follow the stack's conventions where used: Reitit data routes and coercion at the adapter; Pedestal interceptors are adapters and must not hold domain logic; Component/Integrant for the lifecycle; keep the handler a thin map-to-map function calling an app-layer function. Project rules win. These conventions map directly onto inbound adapters. ([source](https://pedestal.io/))
- **`CLJ-FW-03`** (AVOID) Do not put the Component/Integrant system into Ring request maps wholesale; inject only the needed collaborators through closures or middleware (`wrap-deps`); do not let handlers reach into `system` via a global atom/var. Passing the whole system hides dependencies (service-locator smell). ([source](https://github.com/stuartsierra/component))
- **`CLJ-FW-04`** (SHOULD) Footguns: Mount's namespace-level state disables independent test systems; `wrap-params` ordering (it must precede `wrap-keyword-params` and body parsers); `ring-json` keywordizing untrusted keys (`keyword` interning); Reitit middleware order is per-route data, not global; Pedestal interceptor `:enter`/`:leave` order is reversed on leave. Documented ordering mistakes. ([source](https://github.com/ring-clojure/ring/wiki))

## Top 10 footguns

1. Reflection: `(defn len [s] (.length s))` with no hint -> `(set! *warn-on-reflection* true)` per namespace and `^String s`. ([source](https://clojure.org/reference/java_interop))
2. Laziness escaping scope: `(with-open [r (reader f)] (line-seq r))` returned -> `doall`, `(into [] ...)` or `reduce` inside the scope. ([source](https://clojure.org/reference/lazy))
3. Side effects in `swap!`/`dosync` (`(swap! a (fn [x] (send-email!) ...))`) -> a pure function, then the effect after the commit. ([source](https://clojure.org/reference/atoms))
4. `map` for side effects (`(map save! items)`) -> `run!` or `doseq`. ([source](https://guide.clojure.style))
5. Blocking inside a core.async `go` (`(go (jdbc/execute! ...))`) -> `a/thread` or `a/io-thread` and bounded channels. ([source](https://github.com/clojure/core.async))
6. `read-string` or runtime code evaluation on input -> `clojure.edn/read-string` or JSON. ([source](https://cheatsheetseries.owasp.org/cheatsheets/Deserialization_Cheat_Sheet.html))
7. `nil` vs `false`: `(or (:enabled cfg) true)` turns `false` into `true` -> `(get cfg :enabled true)`. ([source](https://guide.clojure.style))
8. Unpinned dependencies (`{:mvn/version "RELEASE"}`) and no lockfile -> exact versions and full git SHAs, `-Stree` diffing. ([source](https://clojure.org/reference/deps_edn))
9. Namespace-level state (`(def conn (connect!))`, Mount globals) -> a lifecycle map via Integrant `init-key`. ([source](https://github.com/weavejester/integrant))
10. Mixed numerics: `(+ Long/MAX_VALUE 1)` throws, `(= 1 1.0)` is false, doubles for money -> `+'`, `bigdec`, normalise key types. ([source](https://clojure.org/guides/equality))
