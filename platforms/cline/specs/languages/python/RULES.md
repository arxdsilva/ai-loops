# Python rules

Python 3.14 and 3.15 (3.15 released 2026-10-09; 3.10 EOL 2026-10-01), as of 2026-11. Source: `research/languages/python.md` (rule IDs kept; verified round 2). Pack data: `specs/languages/python/pack.json`. Universal rules are not repeated here: layers, ports, errors and consistency are in `specs/ARCHITECTURE.md`, SOLID in `specs/SOLID.md`, the gate and race policy in `specs/WORKFLOW.md §6`. Project rules win over these defaults; log each override with `loops run override`.

## REPO

Repository and project management.

- **`PY-REPO-01`** (MUST) Use the `src/` layout: the import package lives in `src/<pkg>/`, tests in a top-level `tests/`. A flat layout lets the working directory shadow the installed package, so tests pass against code that will not ship. ([PyPA: src vs flat layout](https://packaging.python.org/en/latest/discussions/src-layout-vs-flat-layout/); [pytest good practices](https://docs.pytest.org/en/stable/explanation/goodpractices.html))
- **`PY-REPO-02`** (MUST) Declare all metadata in `pyproject.toml` (PEP 621 `[project]`, `requires-python`, `[build-system]`); no `setup.py` or `setup.cfg` for new code. One declarative file that every tool reads. ([PyPA: writing pyproject.toml](https://packaging.python.org/en/latest/guides/writing-pyproject-toml/))
- **`PY-REPO-03`** (SHOULD) Put dev, test and lint dependencies in PEP 735 `[dependency-groups]` (`dev`, `test`, `lint`), not in `[project.optional-dependencies]`. Groups are never published to PyPI and are not extras users can request. ([PEP 735](https://peps.python.org/pep-0735/))
- **`PY-REPO-04`** (SHOULD) Manage the project with `uv`: `uv init`, `uv add`, `uv lock`, `uv sync --locked`, `uv run`; commit `uv.lock` for services. One fast tool replaces pip, venv, pip-tools and pyenv; the lock gives reproducible installs. ([uv: project layout](https://docs.astral.sh/uv/concepts/projects/layout/))
- **`PY-REPO-05`** (MUST) When `uv.lock` exists, CI installs with `uv sync --locked` (fails if the lock is stale) and never plain `uv sync`; non-uv projects use `pip install --require-hashes -r requirements.txt` or `poetry install --sync`. A stale lock must break the build, not silently re-resolve. ([uv: Docker integration](https://docs.astral.sh/uv/guides/integration/docker/))
- **`PY-REPO-06`** (SHOULD) If you cannot use uv, pin with `pip-tools` (`pip-compile --generate-hashes`) or Poetry (`poetry.lock`) and install with `--require-hashes`; keep one tool per repo. Mixed tools produce two sources of truth. ([pip: secure installs / hash-checking](https://pip.pypa.io/en/stable/topics/secure-installs/))
- **`PY-REPO-07`** (SHOULD) Treat `pylock.toml` (PEP 751) as the interchange format: export it for auditors and installers when the tool supports it; do not hand-edit it. Standard, hash-bearing lock that pip-audit and installers can read. ([PEP 751](https://peps.python.org/pep-0751/); [pip-audit `--locked`](https://github.com/pypa/pip-audit))
- **`PY-REPO-08`** (SHOULD) Libraries declare ranges (`requests>=2.32,<3`); applications get exact versions from the lock; never `==` pins in `[project].dependencies` of a library. Exact pins in a library cause resolver conflicts for consumers. ([PyPA: install_requires vs requirements](https://packaging.python.org/en/latest/discussions/install-requires-vs-requirements/))
- **`PY-REPO-09`** (MUST) Pin the interpreter in `.python-version` and `requires-python`; test the full supported matrix (for example 3.12, 3.13, 3.14) in CI. Avoids "works on my 3.14" drift. ([uv: Python versions](https://docs.astral.sh/uv/concepts/python-versions/))
- **`PY-REPO-10`** (SHOULD) Use a uv workspace (`[tool.uv.workspace] members = [...]`) for several interdependent packages in one repo; use separate projects when members have conflicting requirements. One lock and one venv keep versions consistent; conflicting needs break it. ([uv: workspaces](https://docs.astral.sh/uv/concepts/projects/workspaces/))
- **`PY-REPO-11`** (SHOULD) Enable Dependabot or Renovate for `uv`/`pip` ecosystems and GitHub Actions, grouped weekly. Dependency drift is a security debt. ([Dependabot: uv support](https://docs.github.com/en/code-security/dependabot/ecosystems-supported-by-dependabot/supported-ecosystems-and-repositories))
- **`PY-REPO-12`** (SHOULD) Version with SemVer (or CalVer for apps), release by `v<version>` tag; build with `uv build`, publish with PyPI Trusted Publishing (OIDC), never a long-lived token. Short-lived credentials and attestations reduce supply-chain risk. ([PyPI: Trusted Publishers](https://docs.pypi.org/trusted-publishers/); [uv: build and publish](https://docs.astral.sh/uv/guides/package/))
- **`PY-REPO-13`** (MUST) Ship `.gitignore` entries for `__pycache__/`, `*.py[cod]`, `.venv/`, `.pytest_cache/`, `.mypy_cache/`, `.ruff_cache/`, `.coverage*`, `coverage.xml`, `htmlcov/`, `dist/`, `*.egg-info/`. Prevents committing caches and build output. ([GitHub gitignore Python template](https://github.com/github/gitignore/blob/main/Python.gitignore))
- **`PY-REPO-14`** (SHOULD) Run `ruff`, `ruff format --check` and a lockfile check in pre-commit; CI runs the same commands, not a different set. One definition of "clean". ([pre-commit](https://pre-commit.com/); [ruff pre-commit](https://github.com/astral-sh/ruff-pre-commit))
- **`PY-REPO-15`** (SHOULD) CI order matches the gate: `uv sync --locked` → `ruff format --check` → `ruff check` → type check → `import-linter` → tests with coverage → `pip-audit` → build; cache `UV_CACHE_DIR` keyed on `uv.lock`. Fail fast and cheap first. ([uv: GitHub Actions](https://docs.astral.sh/uv/guides/integration/github/))
- **`PY-REPO-16`** (SHOULD) Conventional commits and a generated changelog work unchanged for Python. Not ecosystem-specific. ([Conventional Commits 1.0](https://www.conventionalcommits.org/en/v1.0.0/))

## TOOL

Toolchain.

- **`PY-TOOL-01`** (MUST) Target the newest 3.x that your dependencies support (3.14 or 3.15 as of 2026-11); drop a minor when it reaches EOL (3.10 EOL 2026-10-01). Security fixes stop at EOL; yearly cadence (October). ([Python devguide: versions](https://devguide.python.org/versions/))
- **`PY-TOOL-02`** (SHOULD) Install and pin interpreters with `uv python install` / `.python-version` (alternatives: pyenv, asdf). Reproducible interpreter without OS packages. ([uv: Python versions](https://docs.astral.sh/uv/concepts/python-versions/))
- **`PY-TOOL-03`** (MUST) Format with `ruff format` (Black-compatible); check-only argv `ruff format --check .`; drop black and isort (`ruff check --select I` covers import sorting). One fast tool, one config. ([Ruff formatter](https://docs.astral.sh/ruff/formatter/))
- **`PY-TOOL-04`** (MUST) Lint with `ruff check .` and select rules explicitly (`E, F, W, I, B, UP, SIM, C4, PT, RUF, S, ASYNC, PERF, TID, ARG`); default set is only `E4, E7, E9, F`. Defaults miss bugbear, security and async rules. ([Ruff rules](https://docs.astral.sh/ruff/rules/); [Ruff linter](https://docs.astral.sh/ruff/linter/))
- **`PY-TOOL-05`** (SHOULD) In CI use `ruff check --output-format=github` (also `sarif`, `junit`, `json`); `--fix` only locally and only with safe fixes. CI should annotate, not mutate. ([Ruff configuration: output formats](https://docs.astral.sh/ruff/configuration/))
- **`PY-TOOL-06`** (SHOULD) Keep config in `pyproject.toml` `[tool.ruff]` / `[tool.ruff.lint]`; the nearest config wins and configs are not merged, so use `extend`. Hierarchical configs surprise monorepos. ([Ruff configuration](https://docs.astral.sh/ruff/configuration/))
- **`PY-TOOL-07`** (MUST) Type-check in strict mode: `mypy --strict` (or `pyright` with `typeCheckingMode = "strict"`); one checker is the gate, the other is optional. Strict flags catch untyped defs, `Any` leaks and unused ignores. ([mypy command line: --strict](https://mypy.readthedocs.io/en/stable/command_line.html); [pyright configuration](https://microsoft.github.io/pyright/#/configuration))
- **`PY-TOOL-08`** (SHOULD) Adopt typing gradually on legacy code: `strict = true` per package via `[[tool.mypy.overrides]]`, not a global off-switch; ban bare `# type: ignore` (use `ignore[code]`, enforced by `warn_unused_ignores`). Prevents a green gate that checks nothing. ([mypy config file](https://mypy.readthedocs.io/en/stable/config_file.html))
- **`PY-TOOL-09`** (SHOULD) Use modern typing: PEP 604 `X | None`, PEP 585 builtin generics (`list[int]`), PEP 695 `type` aliases and `class Box[T]` on 3.12+, `typing.Protocol` for ports. Less import noise, native syntax. ([PEP 604](https://peps.python.org/pep-0604/); [PEP 695](https://peps.python.org/pep-0695/))
- **`PY-TOOL-10`** (MUST) Scan dependencies with `pip-audit` (`pip-audit --locked .`, or `-r requirements.txt --require-hashes`); exit 1 means vulnerabilities; generate SBOMs with `-f cyclonedx-json`. PyPA-maintained auditor using PyPI/OSV advisories. ([pip-audit](https://github.com/pypa/pip-audit))
- **`PY-TOOL-11`** (SHOULD) Check licences with a policy tool (`pip-licenses` or `licensecheck`) when policy requires it. Copyleft surprises. ([pip-licenses](https://pypi.org/project/pip-licenses/))
- **`PY-TOOL-12`** (SHOULD) Editor baseline: Pylance/pyright or `basedpyright`, ruff language server (`ruff server`); turn off other format-on-save providers (black, autopep8). Two formatters fight. ([Ruff editor setup](https://docs.astral.sh/ruff/editors/))

## ARCH

Architecture.

- **`PY-ARCH-01`** (MUST) Layer as `domain` → `application` → `adapters`; dependencies point inward only (`ARCHITECTURE` §1). Testable core. ([Cosmic Python](https://www.cosmicpython.com/book/chapter_02_repository.html))
- **`PY-ARCH-02`** (MUST) Packages are directories with (or, as namespace packages, without) `__init__.py`; the module name is the dotted path under `src/` (`orders.domain.order` = `src/orders/domain/order.py`). Needed to resolve imports for the arch checker (`resolver: dotted-module`). ([Python import system](https://docs.python.org/3/reference/import.html))
- **`PY-ARCH-03`** (MUST) Layer checks on Python imports must understand `ast` semantics (`Import`, `ImportFrom` with `level`, multi-line and aliased imports, `if TYPE_CHECKING:` as real edges unless the project opts out); a regex does not. The pack therefore sets `arch.parser: none` and delegates to import-linter (`PY-ARCH-05`). ([ast module](https://docs.python.org/3/library/ast.html))
- **`PY-ARCH-04`** (MUST) Python has no visibility modifiers: underscore prefix means private by convention; export a public API with `__all__` in package `__init__.py`; cycles between modules are legal but break at import time, so forbid them. Cycles cause partial-import `ImportError`. ([PEP 8: public and internal interfaces](https://peps.python.org/pep-0008/#public-and-internal-interfaces))
- **`PY-ARCH-05`** (MUST) Enforce layers with `import-linter`: a `layers` contract (`orders.adapters`, `orders.application`, `orders.domain`, top to bottom), plus a `forbidden` contract from `orders.domain` to `sqlalchemy`, `fastapi`, `django`, `requests`, `httpx`, `pydantic` (if the domain is kept pure); run `lint-imports`. The gate's `import-linter` check runs when `.importlinter` exists; the python-engineer adds it in wave 0. ([import-linter](https://import-linter.readthedocs.io/en/stable/))
- **`PY-ARCH-06`** (MUST) Wire dependencies by hand in `compose.py` (a `build_app(settings)` function) or with FastAPI `Depends` only at the inbound edge; no service locator, no module-level singletons that open connections at import. Import-time side effects break tests. ([FastAPI Depends](https://fastapi.tiangolo.com/tutorial/dependencies/); [Cosmic Python: DI](https://www.cosmicpython.com/book/chapter_13_dependency_injection.html))
- **`PY-ARCH-07`** (MUST) Keep the domain pure: no `import os, requests, httpx, sqlalchemy, django, fastapi, boto3, logging config`, and no `datetime.now()`, `datetime.utcnow()`, `time.time()`, `random.*`, `uuid.uuid4()`, `os.environ`; inject `Clock`, `IdGenerator` ports. Determinism and testability. ([Cosmic Python](https://www.cosmicpython.com/book/chapter_01_domain_model.html))
- **`PY-ARCH-08`** (MUST) Define ports as `typing.Protocol` in the application layer, owned by the consumer; adapters satisfy them structurally without inheriting; use `abc.ABC` only when shared behaviour is needed. Duck typing with static checking. ([PEP 544](https://peps.python.org/pep-0544/); [typing: Protocol](https://docs.python.org/3/library/typing.html#typing.Protocol))
- **`PY-ARCH-09`** (SHOULD) Keep ports small (1 to 5 methods); one use case per module/class; functions at most about 40 lines, at most 5 parameters (keyword-only after `*`); modules under about 400 lines. SRP/ISP in Python units. ([Ruff PLR0913/PLR0915](https://docs.astral.sh/ruff/rules/too-many-arguments/))
- **`PY-ARCH-10`** (MUST) Map transport schemas (Pydantic models, Django serializers) to domain objects at the adapter; never return ORM models or Pydantic request models from use cases. Leaking persistence/transport types couples the core. ([Cosmic Python](https://www.cosmicpython.com/book/chapter_02_repository.html))
- **`PY-ARCH-11`** (SHOULD) Domain events are frozen dataclasses raised by aggregates and dispatched by the application layer after commit (outbox for cross-service). Prevents lost or phantom events. ([Cosmic Python: events](https://www.cosmicpython.com/book/chapter_08_events_and_message_bus.html))
- **`PY-ARCH-12`** (SHOULD) Start as a modular monolith (one deployable, one package per bounded context, import-linter `independence` contracts between contexts) and split to services only on a measured need. Operational cost of microservices. ([import-linter: independence](https://import-linter.readthedocs.io/en/stable/))

## IDIOM

Idioms.

- **`PY-IDIOM-01`** (MUST) Raise specific exceptions from a per-package hierarchy rooted at one base (`class OrdersError(Exception)`); catch the narrowest type; never bare `except:` or `except Exception: pass`; chain with `raise X from err`. Swallowed errors hide data loss. ([Python tutorial: errors](https://docs.python.org/3/tutorial/errors.html); [Ruff E722, BLE001, TRY](https://docs.astral.sh/ruff/rules/blind-except/))
- **`PY-IDIOM-02`** (MUST) Do not catch `BaseException`; `asyncio.CancelledError` is a `BaseException` and must be re-raised after cleanup. Swallowing cancellation hangs shutdown and timeouts. ([asyncio task docs](https://docs.python.org/3/library/asyncio-task.html))
- **`PY-IDIOM-03`** (MUST) Represent absence with `T | None` and narrow explicitly; return `None` only when "no result" is a normal outcome, otherwise raise; never use mutable `None` sentinel tricks for defaults. Type checkers then force the check. ([PEP 604](https://peps.python.org/pep-0604/); [mypy: optional types](https://mypy.readthedocs.io/en/stable/kinds_of_types.html#optional-types-and-the-none-type))
- **`PY-IDIOM-04`** (MUST) Never use a mutable default argument (`def f(x=[])`); use `None` and create inside, or `field(default_factory=list)` in dataclasses. Default is evaluated once and shared. ([Ruff B006](https://docs.astral.sh/ruff/rules/mutable-argument-default/); [Python tutorial: default values](https://docs.python.org/3/tutorial/controlflow.html#default-argument-values))
- **`PY-IDIOM-05`** (SHOULD) Use `@dataclass(frozen=True, slots=True)` (or `typing.NamedTuple`) for value objects and DTOs; use Pydantic models only at the edge for parsing. Immutability, hashability, less memory. ([dataclasses](https://docs.python.org/3/library/dataclasses.html))
- **`PY-IDIOM-06`** (SHOULD) Model closed sets with `enum.Enum`/`StrEnum` and `Literal`; handle them with `match` and finish with `assert_never` (`typing.assert_never`) so a new member fails type checking. Exhaustiveness. ([PEP 634](https://peps.python.org/pep-0634/); [typing.assert_never](https://docs.python.org/3/library/typing.html#typing.assert_never))
- **`PY-IDIOM-07`** (SHOULD) Avoid `Any`; use `object`, `TypeVar`/PEP 695 generics, `Protocol`, or `TypedDict`; at untyped boundaries cast once with a validated parser. `Any` disables checking transitively. ([mypy: dynamic typing](https://mypy.readthedocs.io/en/stable/dynamic_typing.html); [Ruff ANN401](https://docs.astral.sh/ruff/rules/any-type/))
- **`PY-IDIOM-08`** (MUST) Acquire every resource with `with` / `async with` (files, sockets, DB sessions, locks, HTTP clients, temp dirs); write custom ones with `contextlib.contextmanager` / `asynccontextmanager`. Deterministic release; no leaked connections. ([with statement](https://docs.python.org/3/reference/compound_stmts.html#with); [contextlib](https://docs.python.org/3/library/contextlib.html))
- **`PY-IDIOM-09`** (MUST) Use timezone-aware datetimes only: `datetime.now(UTC)` (`datetime.UTC`, 3.11+), store UTC, convert at the edge with `zoneinfo`; never `datetime.utcnow()` (deprecated 3.12) or naive `now()`. Naive datetimes cause DST and offset bugs. ([datetime](https://docs.python.org/3/library/datetime.html); [zoneinfo](https://docs.python.org/3/library/zoneinfo.html))
- **`PY-IDIOM-10`** (MUST) Use `Decimal` (or integer minor units) for money; never `float`; compare with `math.isclose` when floats are unavoidable. Binary float rounding. ([decimal](https://docs.python.org/3/library/decimal.html))
- **`PY-IDIOM-11`** (MUST) Define `__eq__` and `__hash__` together (dataclasses with `frozen=True` do it); never mutate objects that are dict keys or set members. Hash invariants. ([data model: `__hash__`](https://docs.python.org/3/reference/datamodel.html#object.__hash__))
- **`PY-IDIOM-12`** (SHOULD) Follow PEP 8 naming (`snake_case` functions, `CapWords` classes, `UPPER_CASE` constants) and write Google or NumPy style docstrings on public API per PEP 257. Consistent, tool-readable. ([PEP 8](https://peps.python.org/pep-0008/); [PEP 257](https://peps.python.org/pep-0257/))
- **`PY-IDIOM-13`** (AVOID) Avoid metaprogramming in business code (`setattr`, `__getattr__`, metaclasses, `exec` and string evaluation, import hooks, monkey-patching); allow decorators and `__init_subclass__` for cross-cutting concerns and frameworks. Defeats static analysis. ([Ruff S102/S307](https://docs.astral.sh/ruff/rules/exec-builtin/); [Python data model](https://docs.python.org/3/reference/datamodel.html))
- **`PY-IDIOM-14`** (MUST) Import at the top of the module, absolute imports within the package, no `from x import *`, no import-time side effects (I/O, config reads, thread starts). Predictable load order, no cycles. ([PEP 8: imports](https://peps.python.org/pep-0008/#imports); [Ruff F403, PLC0415](https://docs.astral.sh/ruff/rules/import-outside-top-level/))
- **`PY-IDIOM-15`** (MUST) Do not use `assert` for runtime validation (stripped under `-O`); raise a real exception. Validation vanishes in optimised mode. ([assert statement](https://docs.python.org/3/reference/simple_stmts.html#assert); [bandit B101](https://bandit.readthedocs.io/en/latest/plugins/b101_assert_used.html))
- **`PY-IDIOM-16`** (SHOULD) Use comprehensions and generators; build strings with `"".join` or f-strings (never `+=` in a loop), use `pathlib.Path` instead of `os.path`, `enumerate`/`zip(strict=True)` instead of index loops. Readability and speed. ([Ruff PERF, PTH, B905](https://docs.astral.sh/ruff/rules/zip-without-explicit-strict/))

## CONC

Concurrency and the race policy.

- **`PY-CONC-01`** (MUST) Pick the model per workload: `asyncio` for I/O fan-out, threads (`ThreadPoolExecutor`) for blocking libraries, processes (`ProcessPoolExecutor`, `multiprocessing`) for CPU-bound work, sub-interpreters (`concurrent.interpreters`, 3.14) as the new option. The GIL serialises Python bytecode in the default build. ([concurrent.futures](https://docs.python.org/3/library/concurrent.futures.html); [What's new 3.14](https://docs.python.org/3.14/whatsnew/3.14.html))
- **`PY-CONC-02`** (SHOULD) Free-threaded CPython (PEP 703) is officially supported since 3.14 (PEP 779; single-thread slowdown about 5-10%); do not assume it: check `sysconfig.get_config_var("Py_GIL_DISABLED")` and `sys._is_gil_enabled()`; importing a C extension without support re-enables the GIL unless `PYTHON_GIL=0`. Behaviour differs by build and by dependency. ([What's new 3.14](https://docs.python.org/3.14/whatsnew/3.14.html); [py-free-threading: running with GIL disabled](https://py-free-threading.github.io/running-gil-disabled/))
- **`PY-CONC-03`** (MUST) The GIL does not make compound operations atomic (`x += 1`, check-then-act on dicts, lazy init); guard shared mutable state with `threading.Lock`, or confine it to one thread/task and communicate with `queue.Queue` / `asyncio.Queue`. Races exist on GIL builds too and surface on free-threaded builds. ([threading](https://docs.python.org/3/library/threading.html); [py-free-threading: porting guide](https://py-free-threading.github.io/porting/))
- **`PY-CONC-04`** (SHOULD) Prefer immutability and message passing; use `contextvars` instead of globals for request context, and `threading.local` only for thread-affine resources. Fewer shared writes. ([contextvars](https://docs.python.org/3/library/contextvars.html))
- **`PY-CONC-05`** (MUST) Race detection that exists: (a) `pytest-run-parallel` on free-threaded builds (`--parallel-threads`, `--iterations`, `--skip-thread-unsafe`); (b) a TSan CPython build (`--disable-gil --with-thread-sanitizer`, `TSAN_OPTIONS`, `pytest -s`, no xdist); (c) `pytest-randomly` and `pytest-xdist` expose order and shared-state bugs but do not detect races. Be honest about coverage of each tool. ([pytest-run-parallel](https://github.com/Quansight-Labs/pytest-run-parallel); [py-free-threading: TSan](https://py-free-threading.github.io/thread_sanitizer/))
- **`PY-CONC-06`** (MUST) Race policy is `none` plus the substitute: the full gate's `test` check (the only entry in `race.checks`) is required, must pass and must not skip; never run it with `-p no:randomly`, a fixed order or a retry plugin. If the substitute cannot run, the gate fails with a preflight message (WORKFLOW §6). Keeps the hard test gate meaningful. ([pytest-randomly](https://github.com/pytest-dev/pytest-randomly); [Python dev mode](https://docs.python.org/3/library/devmode.html))
- **`PY-CONC-07`** (MUST) Never call blocking code in `async def` (`requests`, `time.sleep`, sync DB drivers, file I/O, `subprocess.run`); use async equivalents or `await asyncio.to_thread(...)`; enable `ruff` rules `ASYNC`. One blocked call stalls every request. ([asyncio: to_thread](https://docs.python.org/3/library/asyncio-task.html); [FastAPI: async](https://fastapi.tiangolo.com/async/))
- **`PY-CONC-08`** (MUST) Use `asyncio.TaskGroup` (3.11+) for structured concurrency, and handle `ExceptionGroup` with `except*`; avoid bare `asyncio.create_task` without keeping a reference (weakly referenced tasks can be collected mid-run) and avoid `gather` without `return_exceptions` on long-lived work. Failures cancel siblings, no orphan tasks. ([asyncio task docs](https://docs.python.org/3/library/asyncio-task.html); [Ruff RUF006](https://docs.astral.sh/ruff/rules/asyncio-dangling-task/))
- **`PY-CONC-09`** (MUST) Wrap every outbound await in `async with asyncio.timeout(seconds)` (catch `TimeoutError` outside the block); re-raise `CancelledError` after cleanup; do not call `uncancel()` in application code. Timeouts are implemented by cancellation. ([asyncio task docs](https://docs.python.org/3/library/asyncio-task.html))
- **`PY-CONC-10`** (SHOULD) Bound concurrency with `asyncio.Semaphore` or `asyncio.Queue(maxsize=n)`; never spawn one task per unbounded input item. Backpressure. ([asyncio sync](https://docs.python.org/3/library/asyncio-sync.html))
- **`PY-CONC-11`** (MUST) Use a job framework for background work (Celery, Dramatiq, arq, or a DB-backed queue); handlers are idempotent and acknowledge after success (at-least-once); shut workers down on `SIGTERM` after finishing the in-flight job. Process restarts are normal. ([Celery: tasks best practices](https://docs.celeryq.dev/en/stable/userguide/tasks.html))
- **`PY-CONC-12`** (SHOULD) Run threaded tests with a timeout (`pytest-timeout`, `faulthandler_timeout`) and a small `sys.setswitchinterval` to widen race windows on GIL builds. Hangs and masked races. ([py-free-threading: testing](https://py-free-threading.github.io/testing/))

## TEST

Testing.

- **`PY-TEST-01`** (MUST) Use `pytest` as the only runner (it also runs `unittest.TestCase`); integration via the same runner with markers. De-facto standard, fixtures and plugins. ([pytest docs](https://docs.pytest.org/en/stable/))
- **`PY-TEST-02`** (MUST) Tests live in top-level `tests/` (`tests/unit`, `tests/integration`); files `test_*.py` or `*_test.py`; functions `test_*`; classes `Test*` with no `__init__`; set `testpaths = ["tests"]` and `--import-mode=importlib`. Discovery rules; avoids `sys.path` hacks. ([pytest good practices](https://docs.pytest.org/en/stable/explanation/goodpractices.html))

## SEC

Security.

- **`PY-SEC-01`** (MUST) Use parameterised queries (`cursor.execute(sql, params)`, SQLAlchemy `text()` with bind params, Django ORM); never f-strings or `%` into SQL; no `subprocess` with `shell=True` or `os.system` on user input (pass an argv list); Jinja2 autoescape on. OWASP A03 injection. ([OWASP SQL Injection Prevention](https://cheatsheetseries.owasp.org/cheatsheets/SQL_Injection_Prevention_Cheat_Sheet.html); [Ruff S608, S602, S605](https://docs.astral.sh/ruff/rules/hardcoded-sql-expression/))
- **`PY-SEC-02`** (MUST) Never `pickle.loads`, `marshal`, `shelve`, `yaml.load` (use `yaml.safe_load`), or `torch.load` without `weights_only=True` on untrusted data; use JSON or a schema (Pydantic, msgpack). Unpickling executes code. ([pickle security warning](https://docs.python.org/3/library/pickle.html); [OWASP Deserialization](https://cheatsheetseries.owasp.org/cheatsheets/Deserialization_Cheat_Sheet.html))
- **`PY-SEC-03`** (MUST) Parse XML with `defusedxml`; do not run input as code (`exec`, `compile` or the expression evaluator). XXE and entity expansion. ([defusedxml](https://pypi.org/project/defusedxml/); [OWASP XXE Prevention](https://cheatsheetseries.owasp.org/cheatsheets/XML_External_Entity_Prevention_Cheat_Sheet.html))
- **`PY-SEC-04`** (MUST) Block SSRF: validate outbound URLs against an allow-list, resolve and re-check IPs, set `follow_redirects=False` unless needed; prevent path traversal with `Path.resolve()` and `is_relative_to(base)`; do not use `tarfile.extractall` or `zipfile` extraction on untrusted archives without `filter="data"` (3.12+). OWASP SSRF and zip slip. ([OWASP SSRF Prevention](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html); [tarfile extraction filters](https://docs.python.org/3/library/tarfile.html#extraction-filters))
- **`PY-SEC-05`** (MUST) CSRF and CORS: Django keeps `CsrfViewMiddleware` on; FastAPI/Flask APIs using cookies need CSRF tokens; never `allow_origins=["*"]` with `allow_credentials=True`. Browser attack surface. ([Django CSRF](https://docs.djangoproject.com/en/stable/ref/csrf/); [FastAPI CORS](https://fastapi.tiangolo.com/tutorial/cors/))
- **`PY-SEC-06`** (MUST) Read secrets from env or a vault via typed settings; never commit them; use `secrets` (not `random`) for tokens; hash passwords with `argon2-cffi` (or `bcrypt`/`scrypt`), not `hashlib.md5/sha1`; compare with `hmac.compare_digest`. OWASP crypto failures. ([secrets](https://docs.python.org/3/library/secrets.html); [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html))
- **`PY-SEC-07`** (MUST) Validate at the adapter boundary with Pydantic v2 models (strict types, `extra="forbid"`, length bounds); the domain receives already-valid value objects. Single validation point. ([Pydantic: models](https://docs.pydantic.dev/latest/concepts/models/); [OWASP Input Validation](https://cheatsheetseries.owasp.org/cheatsheets/Input_Validation_Cheat_Sheet.html))
- **`PY-SEC-08`** (MUST) Supply chain: install with hashes (`uv sync --locked`, or `pip install --require-hashes`), verify package names (typosquatting), use `--no-build` / prebuilt wheels where possible (sdists run `setup.py` code), pin GitHub Actions by SHA, publish with Trusted Publishing and attestations. Install-time code execution. ([pip: secure installs](https://pip.pypa.io/en/stable/topics/secure-installs/); [PyPI attestations](https://docs.pypi.org/attestations/))
- **`PY-SEC-09`** (SHOULD) Run SAST in CI: `bandit -r src -ll -f sarif` (medium and above; `-c` or `[tool.bandit]` config; `--exit-zero` only for reporting) and optionally `ruff --select S` (flake8-bandit port) and Semgrep (`semgrep --config p/python`). Catches code evaluation of strings, weak hashes, `verify=False`, `debug=True`. ([bandit CLI](https://bandit.readthedocs.io/en/latest/man/bandit.html); [Semgrep Python rules](https://semgrep.dev/docs/))
- **`PY-SEC-10`** (MUST) Disable debug in production: Django `DEBUG=False`, `ALLOWED_HOSTS`, `SECURE_*` settings (`manage.py check --deploy`); Flask `debug=False`; FastAPI docs off if not public; never `requests(..., verify=False)`. Information leak, MITM. ([Django deployment checklist](https://docs.djangoproject.com/en/stable/howto/deployment/checklist/); [bandit B501](https://bandit.readthedocs.io/en/latest/plugins/b501_request_with_no_cert_validation.html))

Persistence.

- **`PY-DATA-01`** (SHOULD) Default: SQLAlchemy 2.x (Core + ORM, typed `Mapped[...]`, `select()` style) behind a repository port; raw SQL via `text()` for reports; Django ORM when the project is Django; SQLModel only for tiny CRUD. - **`PY-DATA-03`** (MUST) Migrations with Alembic (`alembic revision --autogenerate`, then review it by hand) or Django migrations; migrations are committed, immutable once released, and applied by a release step, not at app start. Atomic use cases. ([SQLAlchemy: loading relationships](https://docs.sqlalchemy.org/en/20/orm/queryguide/relationships.html); [Django: select_related](https://docs.djangoproject.com/en/stable/ref/models/querysets/#select-related))
- **`PY-DATA-07`** (MUST) Pool connections (`create_engine(pool_size, pool_pre_ping=True, pool_recycle)`, `CONN_MAX_AGE` in Django); use async drivers (`asyncpg`, `psycopg[async]`) with `AsyncSession` only in async stacks; set statement and connect timeouts. Exhaustion and stale connections. ([SQLAlchemy pooling](https://docs.sqlalchemy.org/en/20/core/pooling.html); [SQLAlchemy asyncio](https://docs.sqlalchemy.org/en/20/orm/extensions/asyncio.html))
- **`PY-DATA-08`** (MUST) Set `expire_on_commit=False` for async sessions and never share a session across tasks or threads. Sessions are not thread-safe. ([SQLAlchemy: session basics](https://docs.sqlalchemy.org/en/20/orm/session_basics.html#is-the-session-thread-safe-is-asyncsession-safe-to-share-in-concurrent-tasks))

Django apps own the ORM so a pure hexagon fights the framework. ([Django: applications](https://docs.djangoproject.com/en/stable/ref/applications/); [HackSoft Django Styleguide](https://github.com/HackSoftware/Django-Styleguide))
- **`PY-FW-04`** (SHOULD) Flask: app factory (`create_app`), blueprints as inbound adapters, extensions initialised inside the factory, config from env; no module-level `app` singletons. Testability. ([Flask: application factories](https://flask.palletsprojects.com/en/stable/patterns/appfactories/))
- **`PY-FW-05`** (SHOULD) Django tests: `pytest-django` with `@pytest.mark.django_db`, factories (`factory_boy`) over fixtures JSON; `manage.py makemigrations --check` in CI; `manage.py check --deploy`. Detect schema drift. ([pytest-django](https://pytest-django.readthedocs.io/en/latest/); [Django: makemigrations](https://docs.djangoproject.com/en/stable/ref/django-admin/#makemigrations))
- **`PY-FW-06`** (MUST) Framework footguns: FastAPI blocking call in `async def`, sync dependency with global state, `response_model` leaking ORM fields; Django N+1 in templates/serializers, fat signals, `DEBUG=True` in prod, circular app imports; Flask global `g`/`current_app` outside context. The usual framework traps. ([FastAPI: async](https://fastapi.tiangolo.com/async/); [Django: signals caveats](https://docs.djangoproject.com/en/stable/topics/signals/))

## Top 10 footguns

1. Mutable default argument (`def add(x, acc=[])`) → `acc: list[int] | None = None`, or `field(default_factory=list)`. ([Ruff B006](https://docs.astral.sh/ruff/rules/mutable-argument-default/))
2. Blocking call inside `async def` (`requests.get`) → `httpx.AsyncClient` or `await asyncio.to_thread(...)`. ([FastAPI async](https://fastapi.tiangolo.com/async/))
3. Swallowed `CancelledError`, bare `except`, `except Exception: pass` → catch the narrow type, re-raise `CancelledError`. ([asyncio](https://docs.python.org/3/library/asyncio-task.html))
4. Dangling `asyncio.create_task(job())` with no reference → `TaskGroup`, or keep a set with `add_done_callback(discard)`. ([asyncio](https://docs.python.org/3/library/asyncio-task.html))
5. `pickle.loads` or `yaml.load` on untrusted data → JSON, `yaml.safe_load`, Pydantic. ([pickle](https://docs.python.org/3/library/pickle.html))
6. Naive or deprecated datetimes (`datetime.utcnow()`) → `datetime.now(UTC)` through an injected clock. ([datetime](https://docs.python.org/3/library/datetime.html))
7. `assert` as validation (`assert user.is_admin`) → `raise PermissionError`; asserts vanish under `-O`. ([bandit B101](https://bandit.readthedocs.io/en/latest/plugins/b101_assert_used.html))
8. Import-time side effects and cycles (a DB connection at module import) → build it in `compose.py`; enforce with import-linter. ([import-linter](https://import-linter.readthedocs.io/en/stable/))
9. Float money, mutable hash keys → `Decimal` or integer cents; frozen dataclasses. ([decimal](https://docs.python.org/3/library/decimal.html))
10. Believing the GIL makes code thread-safe (`counter += 1` across threads) → a `Lock` or a queue; test on a free-threaded build with pytest-run-parallel. ([py-free-threading](https://py-free-threading.github.io/testing/))
